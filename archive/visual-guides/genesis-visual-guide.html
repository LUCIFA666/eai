Genesis：新一代多物理仿真平台

高速 GPU 并行、多物理求解器、一统的仿真框架

前面我们学了 MuJoCo（轻量快速、适合 RL）和 Isaac Sim/Lab（高保真渲染、大规模并行）。但它们都有局限：MuJoCo 主要处理刚体，而 Isaac Sim 需要 NVIDIA 显卡。

Genesis 是 2024 年开源的新一代仿真平台，它的核心卖点是：一个框架支持多种物理——刚体、柔体、流体、布料、颗粒都能在同一个场景里交互。而且跑得非常快——单张 RTX 4090 上，Franka 机械臂仿真可达 4300 万 FPS，比实时快 43 万倍。

1. Genesis 架构：一个框架，多种物理

Genesis 架构——多种物理求解器共存于统一框架中

和 MuJoCo / Isaac Sim 的区别
MuJoCo 像一把精密的手术刀——刚体物理做得极好，但不处理流体和布料。Isaac Sim 像一个完整的工厂——功能全面但需要 NVIDIA 硬件。Genesis 的定位是通用物理引擎——刚体、柔体、液体、布料、颗粒都用同一套 API，而且不绑定硬件厂商。

import genesis as gs

gs.init(backend=gs.cpu)            # 选择计算后端

scene = gs.Scene(                   # 创建场景
    sim_options=gs.options.SimOptions(dt=0.01),
    show_viewer=False,              # headless 模式
)

plane = scene.add_entity(           # 添加地面
    gs.morphs.Plane()
)
franka = scene.add_entity(          # 加载 Franka 机械臂（MJCF 格式）
    gs.morphs.MJCF(file="xml/franka_emika_panda/panda.xml")
)

scene.build()                       # 编译物理核心

for i in range(200):                # 推进仿真 200 步
    scene.step()

这段代码做了四件事：初始化后端、创建场景、添加实体、编译并运行。每一个 Genesis 程序都是这个结构。

3. 实战：PD 控制 Franka 机械臂

只是让机器人在重力下自由落体没什么意思。让我们用 PD 控制把关节驱动到一个目标位置。

import genesis as gs
import numpy as np

gs.init(backend=gs.cpu)
scene = gs.Scene(
    sim_options=gs.options.SimOptions(dt=0.01),
    show_viewer=False,
)
scene.add_entity(gs.morphs.Plane())
franka = scene.add_entity(
    gs.morphs.MJCF(file="xml/franka_emika_panda/panda.xml")
)
scene.build()

# 设定目标关节角度 (7 个臂关节 + 2 个手指)
target = np.array([0.0, -0.3, 0.0, -1.5, 0.0, 1.2, 0.8, 0.04, 0.04])

# 设置 PD 增益
franka.set_dofs_kp(np.array([4500, 4500, 3500, 3500, 2000, 2000, 2000, 100, 100]))
franka.set_dofs_kv(np.array([450,  450,  350,  350,  200,  200,  200,  10,  10]))

# 运行 500 步 PD 控制
for step in range(500):
    franka.control_dofs_position(target)
    scene.step()

# 检查最终位置
qpos = franka.get_dofs_position().cpu().numpy()
print("Joint positions:", qpos)
print("Target:         ", target)

4. 加载资产：支持多种格式

Genesis 的一大优势是格式兼容性——不需要手动转换格式。

# MJCF (MuJoCo XML)
franka = scene.add_entity(gs.morphs.MJCF(file="xml/franka_emika_panda/panda.xml"))

# URDF
go2 = scene.add_entity(gs.morphs.URDF(
    file="urdf/go2/urdf/go2.urdf",
    pos=(0.0, 0.0, 0.42),
))

# 基础几何体
box = scene.add_entity(gs.morphs.Box(size=(0.1, 0.1, 0.1), pos=(0.5, 0, 0.5)))
sphere = scene.add_entity(gs.morphs.Sphere(radius=0.05, pos=(0.3, 0, 0.5)))

# OBJ/GLB/STL 网格
mug = scene.add_entity(gs.morphs.Mesh(file="meshes/mug.obj", scale=0.1))

# USD 场景
room = scene.add_entity(gs.morphs.USD(file="scenes/kitchen.usd"))

5. 多物理材质：同一场景中混合不同物理

Genesis 最有特色的能力：同一个场景里，不同物体可以用不同的物理求解器。比如刚体盒子可以和 FEM 柔体球在桌上碰撞。

# 刚体方块 —— 普通碰撞
box = scene.add_entity(gs.morphs.Box(size=(0.1, 0.1, 0.1), pos=(0, 0, 0.5)))

# FEM 弹性体 —— 有限元软体
soft_ball = scene.add_entity(
    gs.morphs.Sphere(pos=(0.2, 0, 0.8), radius=0.06),
    material=gs.materials.FEM.Elastic(E=1e4, nu=0.3, rho=1000),
)

# MPM 沙堆 —— 物质点法
sand = scene.add_entity(
    gs.morphs.Box(pos=(0.4, 0, 0.5), size=(0.1, 0.1, 0.1)),
    material=gs.materials.MPM.Sand(E=1e5, nu=0.2, rho=1500),
)

# SPH 液体 —— 光滑粒子法
water = scene.add_entity(
    gs.morphs.Box(pos=(-0.2, 0, 0.3), size=(0.15, 0.15, 0.15)),
    material=gs.materials.SPH.Liquid(mu=0.001, rho=1000),
)

Genesis 的核心优势：一个 Scene 中混合多种物理求解器

6. GPU 大规模并行：数千环境同时跑

训练 RL 策略时，需要同时运行成千上万个环境。Genesis 原生支持批量仿真——只需要在 build() 时传入 n_envs：

scene.build(n_envs=2048, env_spacing=(0.5, 0.5))

# 所有 API 返回的 tensor 自动变成 [n_envs, ...] 形状
qpos = franka.get_dofs_position()   # shape: [2048, 9]
target = torch.zeros(2048, 9)
franka.control_dofs_position(target)
scene.step()  # 2048 个环境同步推进一步

n_envs=2048：所有环境在 GPU 上并行运行

8. 配置系统

Genesis 用 Python 对象（不是 YAML 文件）做配置，所有参数在创建 Scene 时传入：

scene = gs.Scene(
    sim_options=gs.options.SimOptions(
        dt=0.01,             # 时间步长
        substeps=1,          # 每步子步数
        gravity=(0, 0, -9.81),
    ),
    rigid_options=gs.options.RigidOptions(
        enable_collision=True,
        box_box_detection=True,
    ),
    viewer_options=gs.options.ViewerOptions(
        camera_pos=(3.5, 0.0, 2.5),
        camera_fov=40,
        res=(960, 640),
    ),
    vis_options=gs.options.VisOptions(
        show_world_frame=True,
    ),
    show_viewer=False,
)

9. Genesis vs MuJoCo vs Isaac Sim

对比维度GenesisMuJoCoIsaac Sim/Lab
物理求解刚体 + FEM + MPM + SPH + PBD + IPC刚体为主刚体 + PhysX 柔体
GPU 并行速度4300 万 FPS (Franka)~10 万 FPS~50 万 FPS
资产格式MJCF / URDF / USD / MeshMJCFUSD / Mesh
硬件要求CPU / CUDA / AMD / MetalCPU / CUDANVIDIA 显卡必须
渲染质量光栅化 + 光线追踪基础渲染高保真 RTX 渲染
可微分MPM/Tool solver 支持不支持部分支持
生态成熟度新兴 (2024)，API 还在变成熟稳定成熟，NVIDIA 支持
适合场景多物理实验、快速原型RL 训练、动力学研究高保真场景、Sim2Real
选择建议
Genesis 适合两类人：(1) 需要刚体之外的物理（布料、液体、柔体）的研究者；(2) 想要一个跨平台、统一 API 的快速实验框架。但如果你只做刚体操作任务或 RL 训练，MuJoCo 更成熟稳定；如果你追求最高保真度的 Sim2Real，Isaac Sim 的渲染和物理都更可靠。
