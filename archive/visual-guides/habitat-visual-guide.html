Habitat：室内导航与场景智能体平台

逼真 3D 室内场景、导航任务、标准化评测——具身智能体的"训练场"

前面学的仿真平台——MuJoCo、Isaac Sim、Genesis——主要面向桌面操作（抓、放、装配）。但具身 AI 还有另一大类任务：在室内场景中导航和交互。"走到厨房拿一瓶水"这种任务，需要理解房间布局、避开家具、找到目标物体。

Habitat 是 Meta（Facebook）推出的具身 AI 仿真平台，专门为这类任务设计。它的核心优势是：拥有数千个高保真 3D 室内场景（真实房屋扫描），以及一套标准化的导航任务和评测协议。

2. Habitat 的三层架构

Habitat 由三个组件构成，从底层到上层：

Habitat 三层：Sim（渲染+物理） → Lab（任务+评测） → Gym（标准接口）

3. 场景数据集：真实房屋的数字孪生

Habitat 最有价值的资产是数千个真实室内 3D 场景扫描。这些不是手工建模的虚拟房间，而是用 3D 扫描仪对真实房屋进行重建的结果，包含逼真的家具、墙壁、光照和语义标注。

数据集场景数来源特点
HM3D1,000+Matterport 扫描高质量纹理、语义标注、官方推荐
MP3D90Matterport3D经典数据集、多层建筑
Gibson572Gibson 环境早期数据集、部分质量较低
HSSD211Habitat 合成可交互物体、适合 Rearrange 任务
为什么用真实场景而不是手工建模？
手工建模的虚拟房间往往"太整洁"——家具摆放规则、没有杂物、走廊宽度一致。真实扫描的场景充满了不规则性：窄走廊、堆满杂物的角落、不同房间的光照差异。在这种环境中训练的智能体，迁移到真实世界时表现更好。

4. 任务类型：从"走到那里"到"回答问题"

Habitat 支持的主要任务类型——从简单的点导航到复杂的移动操作

5. Episode 结构：一次任务的完整定义

在 Habitat 中，每次导航任务叫一个 Episode。一个 episode 完整定义了"在哪个场景、从哪出发、去哪里"。

NavigationEpisode — PointNav 示例
episode_id "ep_001" ← 唯一标识符，用于复现
scene_id "data/scene_datasets/hm3d/00801/00801.basis.glb" ← 在哪个 3D 场景中
start_position [3.14, 0.17, -1.82] ← 智能体出生点 (x, y, z)
start_rotation [0, 0.38, 0, 0.92] ← 初始朝向 (quaternion)
goals[0].position [5.62, 0.17, -3.41] ← 目标位置
goals[0].radius 0.2 ← 到达阈值（米），走到 0.2m 内算成功
shortest_path_length 4.37 ← 最优路径长度（米），用于计算 SPL
info.geodesic_distance 4.37 ← 测地距离（沿 NavMesh 的最短距离）

对于 ObjectNav，episode 还包含 object_category（如 "chair"）字段，不直接给坐标——智能体必须自己找到目标物体。

7. 评测指标：怎么判断导航好不好

光看"到了没有"不够——还要看走了多远、有没有绕路。Habitat 定义了标准化的评测指标：

Success（成功率）

智能体主动调用 STOP 动作，且此时距离目标 < success_distance（通常 0.2m）。

注意：走到了但没喊停 = 失败，喊停了但太远 = 也失败。

SPL（Success weighted by Path Length）

成功时，最优路径长度和实际路径长度的比值。走到了但绕了大弯 → SPL 低。

SPL = success × (optimal_dist / max(optimal_dist, agent_dist))
# Habitat 内部计算 SPL 的核心逻辑（简化版）
def compute_spl(success, optimal_distance, agent_distance):
    if not success:
        return 0.0
    return optimal_distance / max(optimal_distance, agent_distance)

# 示例：
# 最优路径 4.0m，智能体走了 5.2m，成功到达
# SPL = 4.0 / 5.2 = 0.77（不错，轻微绕路）

# 最优路径 4.0m，智能体走了 15.0m，成功到达
# SPL = 4.0 / 15.0 = 0.27（绕了很多路）
SPL 的直觉
SPL = 1.0 表示走了最短路径并成功到达——完美导航。SPL = 0.5 表示成功但实际路径是最优的 2 倍。SPL = 0.0 表示失败（没到或走的路太长）。研究论文中 SPL 是最重要的指标，因为它同时衡量了"能不能到"和"走得好不好"。

最简示例：Gym 接口

import gym
import habitat.gym   # 注册 Habitat 的 Gym 环境

env = gym.make("HabitatRenderPick-v0")
obs = env.reset()

done = False
total_reward = 0
steps = 0

while not done:
    action = env.action_space.sample()    # 随机动作
    obs, reward, done, info = env.step(action)
    total_reward += reward
    steps += 1

print(f"Episode 结束：{steps} 步, 总奖励 {total_reward:.2f}")
env.close()

使用 Config 自定义任务

import habitat

# 加载 PointNav 配置（Hydra 风格 YAML）
config = habitat.get_config(
    "benchmark/nav/pointnav/pointnav_habitat_test.yaml",
    overrides=[
        "habitat.environment.max_episode_steps=500",
        "habitat.simulator.agents.main_agent.sim_sensors.rgb_sensor.width=256",
        "habitat.simulator.agents.main_agent.sim_sensors.rgb_sensor.height=256",
    ],
)

# 创建环境
env = habitat.Env(config=config)
obs = env.reset()

# 查看观测空间
print("Observation keys:", obs.keys())
# 输出: dict_keys(['rgb', 'depth', 'pointgoal_with_gps_compass'])

print("RGB shape:", obs["rgb"].shape)         # (256, 256, 3)
print("Depth shape:", obs["depth"].shape)       # (256, 256, 1)
print("Goal (dist, angle):", obs["pointgoal_with_gps_compass"])  # [4.37, 0.82]

# 执行动作
obs = env.step("move_forward")    # 前进 0.25m
obs = env.step("turn_left")       # 左转 10°
obs = env.step("stop")            # 宣布到达

# 获取评测指标
metrics = env.get_metrics()
print(f"Success: {metrics['success']}")
print(f"SPL: {metrics['spl']:.3f}")
print(f"Distance to goal: {metrics['distance_to_goal']:.2f}m")

注册自定义传感器

import habitat
import numpy as np
from gym import spaces

@habitat.registry.register_sensor(name="agent_height_sensor")
class AgentHeightSensor(habitat.Sensor):
    def _get_uuid(self):
        return "agent_height"

    def _get_sensor_type(self):
        return habitat.SensorTypes.POSITION

    def _get_observation_space(self):
        return spaces.Box(low=0, high=5, shape=(1,), dtype=np.float32)

    def get_observation(self, observations, episode, **kwargs):
        agent_state = self._sim.get_agent_state()
        return np.array([agent_state.position[1]], dtype=np.float32)

9. Habitat vs Genesis 速查

对比维度HabitatGenesis
核心任务室内导航、场景交互操作、多物理实验
场景来源真实扫描（HM3D/MP3D）程序化生成或导入
物理引擎Bullet（碰撞检测）刚体+FEM+MPM+SPH+PBD
渲染质量高（真实纹理）高（光线追踪可选）
评测标准SPL、Success 等成熟指标无标准化评测
社区生态成熟、大量论文使用新兴、快速发展
安装难度较高（conda + 下载场景）低（pip install）
适合课程章节第 10 章导航、VLM/VLA第 4 章仿真、第 8 章 RL
一句话总结
Habitat 是室内导航的"ImageNet"——标准化的场景、任务和评测指标，让不同方法可以公平比较。如果你的研究涉及"在室内找东西"或"按指令移动"，Habitat 是事实标准。
