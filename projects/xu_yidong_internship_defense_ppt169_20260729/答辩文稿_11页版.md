## 第3页：四条世界模型路线

这四条技术路线的差异，可以归纳成两个问题：模型预测什么，以及预测结果如何接入决策。

Dreamer 类方法通常预测像素或潜变量，并在想象轨迹中训练策略。DINO-WM 和 LeWM 不强调像素重建，而是预测视觉特征，通过预测特征与目标特征之间的距离进行规划。IRIS 和 Δ-IRIS 将视觉信息离散化为 token，学习 token 的随机动态，并与策略学习结合。TD-MPC2 则进一步面向控制目标，学习与 reward 和 value 有关的潜变量模型，再通过 MPPI 等方法优化动作。

虽然表示方式不同，但我认为它们最终需要回答同一个问题：预测出来的状态，是否保留了对控制真正有用的信息？

---

## 第4页：DINO-WM

DINO-WM 的核心观点是，预训练视觉特征可以直接成为规划空间。

在固定代码版本、随机种子和评估口径后，我得到的 PointMaze 成功率为 1.0。PushT 进行了 50 次评估，成功 43 次，成功率为 86%，Wilson 置信区间为 0.738 到 0.930。Wall 任务成功 47 次，成功率为 94%，置信区间为 0.838 到 0.979。

在这个过程中，我固定了源码提交和 DINOv2 版本，处理了 MuJoCo EGL 和无显示器服务器的兼容问题，并封装了运行、评估和结果统计脚本。评估中固定了随机种子，使用 300 个候选样本、10 个优化步骤和最多 5 次迭代，形成了可重复的 50 次有界评估口径。

我的理解是：如果预训练特征空间保留了可以用于目标匹配的几何结构，那么规划器就不必先还原每一个像素，再进行决策。表征本身就可以构成规划代价。

## 第5页：LeWM

LeWM 使用了一个更简洁的 JEPA 式目标。其中，预测损失负责让模型预测下一时刻的嵌入，SIGReg 用于维持表示的方差，避免表示坍塌。

在规划时，它并不需要生成一张未来图像，而是比较预测终点嵌入与目标嵌入之间的距离，并将这个距离作为 MPC 的优化代价。

使用官方 Push-T 权重进行 50 个 episode 的评估后，成功 48 次，成功率为 96%，总耗时约 363.62 秒。除了最终成功率，我还验证了权重文件的 SHA-256 哈希和严格加载，检查了像素编码、动作编码和下一嵌入预测，确认 MSE 与 SIGReg 都是有限值并能够反向传播，同时验证了数据加载、MPC 候选代价、短训练和 checkpoint 回载。

需要强调的是，这个结果证明的是官方权重和完整推理链路能够工作，并不代表我从头训练出了同等性能。接下来从视觉特征预测转向离散 token 动态，重点讨论如何理解随机未来，而不只是比较生成图像是否好看。

## 第6页：Δ-IRIS 的预测理解

这一页区分两个容易混淆的实验：tokenizer 条件重建和 world model 未来想象。

上方是 tokenizer 条件重建，MAE 为 0.00043786，PSNR 为 57.5892 分贝。这个结果看起来非常好，但编码器在重建过程中已经看到了真实下一帧。因此，它验证的是图像压缩和重建质量，而不是未来预测能力。

下方是 world model 的单步想象，MAE 为 0.00358743，PSNR 为 30.4654 分贝。生成过程中没有输入真实下一帧，所以这一结果才对应条件未来预测。

从图中可以看到，误差主要集中在随机实体的位置上。我的理解是，同一个历史状态和动作之后，可能存在多个合理未来。模型采样出不同的 Δ-token，并不一定代表预测失败，而可能是它正在表达环境中的不确定性。

因此，评价随机世界模型时，不能只选择最好看的一张图，而应该报告未来分布、典型误差以及不确定性出现的位置。

## 第7页：TD-MPC2

TD-MPC2 展示了另一种更加面向控制的世界模型观点：模型只需要预测对控制有用的信息。

它首先使用策略先验提出候选动作，再通过 MPPI 或 CEM 在潜空间中采样和优化动作序列。世界模型预测有限 horizon 内的 reward，并在序列末端使用 Q 函数补充更长期的价值。优化完成后，只执行动作序列的第一步，然后重新观察并滚动规划。

官方 dog-run checkpoint 的单个 episode 回报为 762.2。在我的训练记录中，训练到 154,000 步时回报为 134.0，在 151,000 步附近得到的最高回报为 157.3。

这里同样需要说明边界：较短训练只能证明训练链路可用，不能作为正式论文性能复现。更加严谨的复现应接近官方建议的 700 万步，并报告多个随机种子的均值和方差。

我的理解是，TD-MPC2 规模化的难点不仅是动力学预测，还包括潜表示的稳定性、reward 与 value 的尺度、Q 函数过估计以及多任务接口的一致性。

## 第8页：三条统一判断

综合这四条路线，我形成了三条可以迁移的判断。

第一，表征不等于重建。DINO-WM 和 LeWM 说明，只要特征几何能够支持目标匹配，就不必恢复每一个像素。

第二，预测不等于一张图。Δ-IRIS 说明，随机未来应该通过条件分布、典型误差和不确定性边界来评价。

第三，规划不等于无限延长 rollout。TD-MPC2 使用短期模型预测、terminal Q 和策略先验，也可以形成具有长期决策能力的闭环。

因此，我认为好的世界模型需要同时具备三个条件：任务相关的表示、可校准的不确定性，以及实际的闭环决策价值。最终评价仍然需要回到任务成功率、策略回报、稳定 rollout 和泛化能力，而不能只看生成图像是否逼真。

## 第9页：可复现工程方法

为了把一次运行变成可追溯证据，我总结了一套七步流程。

第一，固定代码提交和模型版本。第二，隔离运行环境，避免依赖互相污染。第三，执行 CUDA、EGL 和环境探针。第四，先运行最小 smoke test，确认主要模块能够连通。第五，严格加载 checkpoint，检查参数是否完全匹配。第六，区分有界评估和正式评估，并提前固定评估口径。第七，交付脚本、日志、哈希、指标和结果图。

在具体项目中，我处理过 DINOv2 和 Transformers 的版本漂移、无显示器服务器上的 MuJoCo EGL 问题，以及 Hydra、nightly 依赖和下载超时等问题。

我认为工程复现的验收标准应该是：每一个结论都能指向对应的命令、日志、指标或者落盘产物，使其他人能够重复和复核。

## 第10页：未来规划

下一步，我希望把世界模型的复现经验迁移到真实机器人决策闭环中。

第一条路径是人形机器人与物体交互。在 HDMI 复现和自定义数据接入的基础上，我希望继续研究接触几何、局部规划以及交互稳定性。

第二条路径是 VLA 与 WAM 的协同。在 π0、OpenPI 和 Flow Matching 的实验基础上，可以让 VLA 提供动作先验，让世界模型进行未来 rollout、风险检查和失败后的重规划。

第三条路径是复杂动力学与 MPC。在无人机—悠悠球系统中，我希望结合残差动力学、潜空间世界模型和 MPC，完善旋转跟随、减摆以及末端捕获闭环。

这三条路线最终指向同一个研究问题：如何学习一种既能够跨场景泛化，又能够被规划器真正使用的预测状态？
