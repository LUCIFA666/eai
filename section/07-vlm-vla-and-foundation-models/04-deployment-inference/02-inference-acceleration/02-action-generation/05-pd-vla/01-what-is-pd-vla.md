# PD-VLA 是什么

PD-VLA 是一种免训练的动作解码加速方法。它不重训、不改网络结构，只把 VLA 原本逐 token 的自回归解码循环换成 Jacobi 式并行迭代：随机初始化整串动作 token，反复用一次前向同时更新所有 token，直到收敛。收敛得到的结果与逐 token 贪心解一致，加速来自迭代次数远少于 token 数。

## 本节目标

建立对 PD-VLA 的整体认识：它在 VLA 加速里的定位、action chunking 为什么让解码变慢、它免训练免改结构的三项特性，以及提速与精度的整体量级。

## 在 VLA 加速里的定位

VLA 从视觉语言骨干继承了很大的参数量，动作又是逐 token 自回归解出的，每一步控制的延迟因此偏高。围绕这层开销已有几条加速路线，各自改动的位置不同：TinyVLA、RoboMamba 重新设计更小的骨干；量化感知训练（如 QAIL）、动态深度早退（如 DeeR-VLA）需要额外训练并改动模型；FastV、SparseVLM、VLA-Cache 这类免训练方法则通过剪枝或缓存 token 来压低单次前向成本，改动落在模型的前向计算里。

PD-VLA 与 OpenVLA-OFT 同属并行动作解码这一类，都用一次前向取代逐 token 串行，但两者的代价不同：OpenVLA-OFT 需要换一套微调配方重训动作生成段，PD-VLA 只改推理时的解码循环。按论文的三项对比，PD-VLA 同时满足不重设计骨干、不训练、不改模型三条，这在上述方法里是唯一的。因为只动解码循环，它与量化、缓存等作用在模型内部的方法互不冲突，可以叠加使用。

## action chunking 为什么让解码变慢

action chunking 指一次预测未来 m 步动作、连续执行完再重新规划。它能显著提升操作成功率、动作连贯性与稳定性，但代价是把动作维度线性放大：7-DoF 机械臂的一步动作是 7 维（3 平移、3 旋转、1 夹爪），一个 m 步的 chunk 就是 7m 维的动作序列。

自回归解码下，单次推理时间随要解的 token 数线性增长，chunk 越长、单次推理越慢，控制频率被压低。高频、需要实时反应的任务恰恰要求高控制频率，这就是 chunking 带来精度收益的同时留下的速度问题。PD-VLA 的目标就是去掉这段随 chunk 变长的解码开销，让 chunking 的精度收益不必以低频为代价。

## 提速与精度量级（论文报告）

PD-VLA 在 CALVIN（ABCD→D）和 LIBERO 四套件上评测。相比基座 LLaVA-VLA，执行频率提到 2.52×；把提速拆开看，并行解码单独把平均解码速度提到 1.28×，action chunking 则通过减少推理次数贡献了其余部分。精度方面，CALVIN 平均完成长度提升 2.34；LIBERO 平均成功率 94.7%、最难的 LIBERO-Long 达 91.7%，均为当时最好。并行解码这一步几乎不损精度，原因在下一节的收敛性里展开。

## 本页小结

- PD-VLA 是免训练的动作解码加速方法，只把逐 token 自回归解码换成 Jacobi 并行迭代，收敛结果与贪心解一致。
- 它与 OpenVLA-OFT 同属并行动作解码，但同时满足不重设计骨干、不训练、不改模型三条，因此与量化、缓存等方法正交可叠加。
- action chunking 把动作维度放大到 7m 维，自回归解码随之变慢、控制频率被压低，PD-VLA 去掉的正是这段随 chunk 变长的开销。
- 相比基座执行频率提到 2.52×，并行解码单独贡献 1.28× 解码速度；LIBERO 平均 94.7%、LIBERO-Long 91.7%（论文报告）。
