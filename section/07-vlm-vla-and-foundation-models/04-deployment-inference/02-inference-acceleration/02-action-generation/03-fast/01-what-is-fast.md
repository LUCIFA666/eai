# FAST 是什么

FAST（Frequency-space Action Sequence Tokenization）是一套连续动作的分词编解码器。它把一段动作块先做离散余弦变换转到频域，量化后再用字节对编码压成少量离散 token，供自回归 VLA 按 next-token 预测；解码时逆着走回连续动作。它替换的是 RT-2、OpenVLA 这类自回归 VLA 常用的逐维均匀分箱，是一段独立于骨干的编解码流程，不修改预训练 transformer，可套用于不同 VLA。

RT-2、OpenVLA 这条路线把动作预测当成语言模型的 next-token 预测：动作要先离散成 token，并入词表，再由预训练 transformer 逐个解出。分词方式因此直接决定 token 序列有多长、每个 token 好不好学，也就决定了训练和推理的成本。FAST 要解决的正是这层分词，而不改动上面的 VLA。

## 逐维分箱替换的对象

逐维均匀分箱把每个动作维度的取值范围切成 256 个等宽区间，动作块里每个时间步、每个维度各出一个 token。一个动作块有 H 个时间步、每步 D 维，token 序列长度就是 H×D。FAST 换掉这套编码：token 数不再由采样率决定，而是贴近动作信号本身的复杂度。

## 高频动作下的两个瓶颈

逐维分箱在高频动作上暴露两个问题，也是 FAST 要解决的对象。

第一个是 token 数随控制频率线性膨胀。序列长度 H×D 里，H 随频率升高而变大，同样一秒的动作块，BridgeV2（5 Hz、7 维）是 35 个 token，DROID（15 Hz、7 维）105 个，双臂叠衣任务（50 Hz、14 维）到 700 个。自回归要逐 token 解出，序列越长，训练和推理越慢。

第二个是每个 token 携带的信息随频率升高而变少。自回归的学习信号来自当前 token 相对前文的边际信息量；动作信号在时间上平滑，采样越密，相邻步差异越小，逐步分箱后相邻 token 高度相关，边际信息趋近于零，收敛变慢。OpenVLA 在低频的 BridgeV2、RT-1 上表现良好，却难以拟合更高频的 DROID，正对应这个瓶颈。这两点的机理和 FAST 的修复方式在下一页展开。

## 压缩的整体量级

FAST 在各数据集上都缩短 token 序列，频率越高收益越大：BridgeV2 压缩 1.75×，DROID 3.6×，双臂叠衣 13.2×。压缩后 token 数稳定在每条机械臂约 30 个（双臂约 60），基本与控制频率无关，说明它找到的表示接近动作信号的内在复杂度。在此基础上训练的通用词表 FAST+，在训练时未见的多种机器人数据上，token 数相对逐维分箱普遍减半甚至更多。

## 本页小结

- FAST 是一段独立于骨干的动作编解码流程，用 DCT+BPE 替换逐维均匀分箱，供自回归 VLA 使用。
- 逐维分箱在高频动作上有两个瓶颈：token 数按 H×D 随频率线性膨胀；相邻 token 边际信息趋零，延缓自回归收敛。
- 压缩比随频率升高（1.75× 到 13.2×），token 数稳定在每臂约 30 个、近乎与频率无关；FAST+ 在未见数据上相对逐维分箱普遍减半。
