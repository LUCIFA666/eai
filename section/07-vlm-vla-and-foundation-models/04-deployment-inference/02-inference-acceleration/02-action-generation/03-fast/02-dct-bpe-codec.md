# DCT 与 BPE 编解码

FAST 的输入是一个形状为 `(H, D)` 的动作块，H 个时间步、每步 D 维；输出是一段变长的离散 token 序列。分词以一秒的动作块为单位，块长 H 随控制频率变化。中间数据流过三种形态：DCT 后的系数矩阵、量化后的稀疏整数矩阵、展平后的一维整数序列。整条流程由归一化、DCT、量化、展平、BPE 五个环节串起，没有可训练的网络：DCT、量化、展平是固定操作，与数据无关；归一化只需从数据算一遍每维分位；唯一要在数据上训练的部件是 BPE 的合并词表。本页先讲清逐维分箱在高频为什么失效、频域压缩为什么能修复，再逐步拆开编码流水线与可逆的解码回路。

## 逐维分箱为什么在高频失效

自回归模型按 next-token 预测训练，给定前缀预测下一个 token，单个 token 贡献的学习信号正比于它相对前缀的边际信息量。逐维均匀分箱把每个维度每个时间步独立切成 256 个等宽区间，各出一个 token。控制频率升高时，相邻时间步之间的动作差异按比例缩小，逐步分箱后相邻 token 高度相关，甚至常常落进同一个区间取同一个值。

这带来一个退化解：模型只要默认复制上一个动作 token，就能在高频数据上拿到很低的 token loss，却没有学到动作本身的动态。边际信息趋零使正确解与这个平凡解在损失上几乎无法区分，训练陷入差的局部最优，收敛显著变慢，高频数据甚至难以拟合。OpenVLA 在低频的 BridgeV2、RT-1 上有效、却难以拟合更高频的 DROID，正是这个退化的表现。

论文用一个插值实验把这个机理从数据复杂度里单独隔离出来。构造一个合成任务：目标是一条插值四个随机点的三次样条，用 256 区间的逐维分箱对目标序列分词，训练一个小的自回归 transformer 去预测。关键操作是只改变信号的采样率（从每序列 25 步到 800 步），底层数据分布始终不变。

逐维分箱在低采样率下误差很低，采样率一升高误差就急剧上升，最终模型退化为直接复制第一个动作。数据复杂度自始至终没变，退化只来自分词方式。换成 DCT 压缩后的 token，误差在所有采样率下都保持很低。这把瓶颈定位在编码而非数据，也说明修复方向是换一套减少 token 间冗余的编码。

## 频域压缩为什么成立

DCT 把一段时域信号表示成一组不同频率余弦分量之和：低频分量刻画信号的整体形状，高频分量对应急剧的跳变。图像压缩里 JPEG 用的正是这个变换，因为自然图像的能量集中在低频。机器人动作在时间上同样平滑，能量因此集中到少数低频系数上，多数高频系数接近零。

写成公式，对某个动作维度长度为 H 的时间序列 `x_0 … x_{H-1}`，正交 DCT-II 给出 H 个频率系数：

```
C_k = sqrt(2/H) · w_k · Σ_{n=0}^{H-1} x_n · cos( π(2n+1)k / (2H) ),   k = 0, …, H-1
w_0 = 1/√2,   w_k = 1 (k ≥ 1)
```

`k=0` 是直流分量，对应整段动作的平均水平；`k` 越大频率越高。平滑动作里大 `k` 的系数普遍接近零，能量集中在前几个 `k` 上。论文正文只写 DCT、未给公式，这里的正交 DCT-II 取自官方实现所用的 scipy `dct(type-II, norm="ortho")`。

压缩就建立在这个能量集中之上：量化时把近零的高频系数取整成 0，在几乎不损失信息的前提下得到每维只留少数显著系数的稀疏表示。这直接回应上一节的退化解，逐维分箱让相邻 token 冗余、边际信息趋零，而频域表示把冗余集中剔除，剩下的每个 token 边际信息更高，自回归重新有真实信号可学。DCT 是解析变换，无需训练，也不像向量量化那样要为每个数据集单独学一个码本。

## 五步编码流水线

<figure>
  <img src="assets/dct_method.png" alt="FAST 编码流水线：归一化动作块经 DCT、量化、展平、BPE 得到动作 token" width="760">
  <figcaption>FAST 编码流水线：归一化动作块先做 DCT 转到频域，量化系数得到稀疏的频率矩阵，按列优先展平成一维整数序列，再由 BPE 压成最终的动作 token。图为论文流水线示意。</figcaption>
</figure>

1. 归一化：按训练集里每个动作维度的第 1 与第 99 分位映射到 `[-1, 1]`。用分位数而非最小最大值，对大规模机器人数据里偶发的离群动作更稳，不会被极值拉扁量程；分位归一化也把不同尺度的跨本体动作放到同一量纲，便于统一分词。

2. DCT：对每个动作维度分别做离散余弦变换，得到该维沿时间方向的一组频率系数。低频刻画整体形状，高频对应跳变，平滑信号的能量集中在少数低频系数上。逐维处理让每个维度的时间结构独立展开，不会互相混叠。

3. 量化：对 DCT 系数做缩放取整 `round(γ · C)`，缩放系数 `γ` 默认取 10。`γ` 越大越接近无损、保留的系数越多、压缩率越低；取整把大量近零的高频系数压成 0，得到每维只留少数显著系数的稀疏矩阵。这是整条流水线里唯一有损的环节，重建误差全部来自这里。

4. 列优先展平：把稀疏系数矩阵拉成一维整数序列，先拼各维度的最低频分量，再依次拼更高频。另一种做法是逐维度把该维所有频率拼完再换下一维。选列优先，是让自回归先预测决定整体形状的低频分量、后补细节，一旦解码早期出错，影响的是整体轮廓而非某一维的全部，rollout 因此更稳定。

5. BPE：在展平后的整数序列上训练字节对编码，默认词表 1024。稀疏序列里有成片的 0 和反复出现的系数组合，BPE 把这些高频共现的相邻符号迭代合并成新符号，成片的 0 被压掉、跨维度常见的组合并成单个 token，一个动作块最终压到数十个 token（单臂约 20–30，双臂约 50–60）。选 BPE 因为它实现高效，且输出是固定大小的词表，能直接并入视觉语言模型已有的词表用于 VLA 训练。

论文的 Algorithm 1 把编码写成下面的形式，其中上标 `i` 是动作维度、下标是频率序号，展平行按频率从低到高、跨维度交错排列：

```
Require: scale γ, BPE 词表 Φ（推理时）
procedure FASTTokenizer(a_{1:H}):
    C^i_j   ← DCT(a^i_{1:H})                       # 逐维 DCT
    C̄^i_j  ← round(γ · C^i_j)                      # 量化
    [T_k]   ← [C̄^1_1, C̄^2_1, …, C̄^1_2, …, C̄^n_H]  # 低频优先展平
    Φ       ← TrainBPE({[T_k]})                    # 仅训练词表时
    [T̄_1, …, T̄_k̄] ← BPE([T_1, …, T_k], Φ)          # BPE 编码
    return action_tokens
```

伪码没有列出归一化：官方实现里归一化不在 codec 内，而在上游数据管线，`UniversalActionProcessor` 收到的已是归一化后的动作，编码从 DCT 起。论文把归一化算作 FAST 第一步，实现则把它归到数据侧，两种视角描述的是同一件事。落成代码，`UniversalActionProcessor.__call__` 的编码核心是：

```python
# 官方 processing_action_tokenizer.py，UniversalActionProcessor.__call__
dct_coeff = dct(action_chunk, axis=1, norm="ortho")   # 逐维 DCT-II
dct_coeff = np.around(dct_coeff * self.scale)          # 量化：缩放后取整
for elem in dct_coeff:                                 # elem 形状 [频率, 维度]
    ints = np.maximum(elem.flatten() - self.min_token, 0).astype(int)
    token_str = "".join(map(chr, ints))               # 每个系数 → 一个 Unicode 字符
    tokens.append(self.bpe_tokenizer(token_str)["input_ids"])  # 展平序列交给 BPE
```

有三个实现细节：量化用 `np.around`，是四舍五入到偶数的银行家舍入；`elem.flatten()` 对 `[频率, 维度]` 矩阵按行展平，即低频优先、跨维度交错，与伪码的展平行一致；每个量化系数减去全局最小值 `min_token` 后经 `chr` 变成一个 Unicode 码点，BPE 因此是在一串字符上做合并，而不是直接处理整数。

## 解码回路

流水线每一步都可逆，token 还原成动作按相反顺序走：逆 BPE 展开回一维整数序列，反展平重排成频率矩阵，除以 `γ` 后对每个维度做逆 DCT 回到时域，再按归一化时保存的分位参数还原到原始动作尺度。除量化的取整外其余步骤都无损，因此重建误差只来自量化，由 `γ` 单一控制：`γ` 大则重建更精、token 更多，`γ` 小则相反。

`UniversalActionProcessor.decode` 正是这条逆链：

```python
decoded = self.bpe_tokenizer.decode(token)                    # 逆 BPE → 字符串
coeff = np.array(list(map(ord, decoded))) + self.min_token    # 字符 → 整数系数
coeff = coeff.reshape(-1, self.action_dim)                    # 反展平回 [H, D]
actions = idct(coeff / self.scale, axis=0, norm="ortho")      # 除以 scale 后逆 DCT
```

`decode` 必须显式传入 `time_horizon` 与 `action_dim`：BPE 解出的是一串没有形状信息的系数，要 `reshape(-1, action_dim)` 重排回频率矩阵、并校验时间步数，就得知道动作块原本的 `(H, D)`。

## 两个超参与对向量量化的取舍

整条流水线只有两个超参：量化前作用在 DCT 系数上的缩放 `γ`，以及 BPE 的词表大小。论文报告二者都不敏感，所有单数据集实验统一用 `γ=10`、词表 1024，无需逐数据集重调。

另一类压缩思路是向量量化（VQ、FSQ 等），学习一个码本把动作编码成离散 token。它的重建质量对超参和网络结构敏感，要按数据集调，还要额外训练一个编码网络。FAST 用解析的 DCT 加一次 BPE 训练取代这套学习式压缩，只留两个不敏感的超参，编解码本身也快。代价是它不像 VQ 那样能端到端适配特定分布，但在机器人动作这种平滑信号上，解析频域表示已经足够。

## 本页小结

- 逐维分箱在高频下相邻 token 冗余、边际信息趋零，催生复制上一个动作的退化解；插值实验在数据不变、只改采样率的条件下复现了这一退化，把瓶颈定位到编码。
- FAST 是一段无网络的编解码流程，动作块流经归一化、DCT、量化、展平、BPE 五步变成 token；频域能量集中让量化剔除近零高频系数后仍近似无损，每个 token 边际信息更高。
- 除量化取整外全流程可逆，重建误差只由缩放 `γ` 控制；`γ` 与 BPE 词表是仅有的两个超参且都不敏感，相比向量量化免去逐集调参与单独训练码本。
