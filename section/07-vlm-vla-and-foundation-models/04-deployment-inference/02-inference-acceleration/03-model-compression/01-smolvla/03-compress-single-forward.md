# 压缩单次前向

SmolVLA 在骨干规模之外，还从四处压低单次前向的成本：只用 VLM 的前一半层、把每帧视觉 token 压缩到 64 个、给 action expert 减窄并交替两种注意力、用少步积分加动作分块摊薄每步开销。

这四处落在同一套成本上。把进骨干的序列长度记作 `L`、隐藏维度记作 `d`，Transformer 每层的开销分两块：自注意力随序列长度平方增长，量级 `O(L²·d)`；前馈 MLP 随宽度平方增长，量级 `O(L·d²)`。层数则是这两块的线性倍数。四处压缩各自命中不同的项：层裁剪把倍数减半，视觉 token 压缩缩短 `L`、作用在平方的注意力项上，专家减窄缩小 `d`、作用在平方的 MLP 项上，少步积分与分块减少这套前向重复的次数。

## 本节目标

理解这四处设计各自压缩单次前向的哪一段、对应哪个配置项，以及消融给出的速度与成功率取舍。

## 层裁剪：只用 VLM 的前一半层

VLM 的前向要逐层经过整个语言解码器，层数直接决定这段成本。SmolVLA 不用最后一层的特征，而是让 action expert 读到第 N 层为止的特征，第 N 层之后的层在训练前就裁掉。取 N 为总层数的一半，配置项 `num_vlm_layers=16`，代码里直接把解码层截成 `layers[:num_vlm_layers]`。SmolLM2 的解码器约 32 层，保留 16 层等于把 LLM 这段的算力降到约一半，action expert 的层数也随之减半。

裁到一半而不是更少，来自速度与成功率的权衡。LIBERO 上按保留层数做的消融里，成功率随 N 增加缓慢上升，收益递减：

| 保留层数 N | LIBERO 平均成功率 |
| --- | --- |
| 8 | 75.0 |
| 16 | 78.5 |
| 24 | 79.5 |
| 32（全层） | 80.3 |

从 16 到 32 只多约 1.8 个点，算力却翻倍。同一组消融里，隔层采样（每两层取一层）为 75.5、把骨干换成更小的 VLM-256M 为 75.8，都不如保留前 16 层。取前一半因此是这组对比里速度与精度平衡最好的一档。

## 视觉 token 压缩：每帧 64 个

进骨干的序列越长，每层注意力越贵，视觉 token 通常是序列里最长的一段。SmolVLM2 本身用图像分块训练，会把同一张图的多个裁剪块连同全局图一起处理，token 数很高。SmolVLA 为了推理更快，不做分块，只保留全局图，再用一次 pixel shuffle 把每帧的视觉 token 压缩到 64 个。图像先按 512×512 做带 padding 的缩放再编码。视觉 token 数一降，进 SmolLM2 解码层的序列就短，每层注意力的成本随之下降。

## action expert 减窄与交替注意力

action expert 这一侧压缩两处。一是宽度：隐藏维度取 VLM 的 0.75 倍，配置项 `expert_width_multiplier=0.75`，每层的矩阵乘更小；MLP 部分随宽度平方缩放，`0.75²≈0.56`，算力约降到六成。二是注意力排布：每个 block 只放一种注意力，交叉注意力和自注意力交替，配置项 `self_attn_every_n_layers=2` 表示每两层插一层 SA、其余为 CA。

这层省算力可以从序列长度看清。记 VLM 前缀（视觉加语言）长度为 `P`、动作块长为 `n`，通常 `P ≫ n`。π0 把前缀和动作拼在一起做全自注意力，每层是 `O((P+n)²)`；交替之后，CA 层只让动作 token 单向读取缓存好的前缀 K/V，降到 `O(n·P)`，SA 层只在动作块内部做、是 `O(n²)`，前缀这段长序列的自注意力不再每层重算。代码按层号分派这两种注意力：

```python
if fill_kv_cache or "cross" not in attention_mode or layer_idx % self_attn_every_n_layers == 0:
    # 自注意力层
else:
    # 交叉注意力层：复用缓存的前缀 K/V
```

算前缀缓存的那一遍（`fill_kv_cache`）所有层都走自注意力；之后每逢 `layer_idx` 是 `self_attn_every_n_layers` 的整数倍放一层 SA，其余走 CA。

交替排布不只是省算力。LIBERO 上对注意力方式的消融里，全 CA 为 79.0、全 SA 为 74.5，交替 CA 与 SA 达到 85.5，同时兼顾成功率与推理速度。自注意力还让生成的动作块更平滑，这一点在真机评测上尤其明显。

## 少步积分与动作分块

动作生成方式决定单次控制要做几次前向。SmolVLA 用 flow matching：推理时从噪声出发积分一条向量场，步数固定为 10（`num_steps=10`），每步一次欧拉更新，十步后得到动作，比多步 diffusion 的几十步低得多。步数能降到十步，与 flow matching 的学习目标有关：目标向量场 `u = ε - A_t` 对应一条近似直线的传输路径，欧拉积分在近直线上几步就能收敛；diffusion 的反向轨迹更弯，同样精度要几十步。这里还有一层 KV 缓存的收益：昂贵的 VLM 前缀在积分循环前只前向一次，K/V 写入缓存（`use_cache`、首步 `fill_kv_cache`）；十步里重复的只是较轻的 action expert，交叉注意力层复用缓存的前缀 K/V。整段积分的 VLM 成本因此只按块付一次，而不是按步付十次。

分块进一步摊薄每步成本。一次前向直接预测一整段动作块，块长 `chunk_size=50`，机器人可以连续执行这段动作再触发下一次推理，单次前向的成本被摊到多个控制步上。块长也有甜点：消融里块长 1 只有 50.0、块长 10 升到 84.0、块长 50 为 80.3、块长 100 降到 74.5，10 到 50 之间成功率最好。块长取得过大，一次预测要覆盖太远的未来，反而变差。

## 本页小结

- 四处压缩落在同一套成本上：每层自注意力 `O(L²·d)`、MLP `O(L·d²)`；层裁剪减层数，视觉 token 缩短 `L`，专家减窄缩小 `d`（`0.75²≈0.56`），少步分块减前向次数。
- 层裁剪只保留 VLM 前 16 层（`num_vlm_layers=16`），约减去一半算力；消融里全层只比半层高约 1.8 个点，取前一半是速度与精度的平衡档。
- 视觉 token 压缩关闭图像分块、只留全局图并做 pixel shuffle，每帧压缩到 64 个，缩短进骨干的序列。
- action expert 减窄到 0.75 倍宽度，交替 CA 与 SA（`self_attn_every_n_layers=2`），比全自注意力省算力且成功率更高（消融 85.5）。
- flow matching 学近直线传输，推理固定 10 步欧拉积分即收敛；VLM 前缀缓存 K/V、十步只重复 action expert 的前向，VLM 成本按块付一次；动作分块（`chunk_size=50`）把单次前向摊到多个控制步，块长 10 到 50 为甜点。
