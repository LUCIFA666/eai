# 动作生成加速

一次推理的延迟里，动作生成这一段把主干输出变成具体动作，它的开销取决于动作的生成方式。自回归要一个 token 接一个 token 串行解码，token 越多越慢；flow 或 diffusion 把动作当成从噪声逐步去噪的过程，要迭代采样很多轮，轮数越多越慢。这一组方法都在压缩这一段成本，区别在于从哪个角度压缩：去掉串行依赖、把迭代步数压到少数几步、减少要解码的 token 数，或者让小模型先草拟再由大模型验证。下面按这四条机制展开。

## 并行动作解码

自回归解码的瓶颈是串行：后一个 token 要等前一个算完，一段动作要几次到几十次前向才能全部生成。并行动作解码去掉这个依赖，一次前向就输出整段动作。

OpenVLA-OFT 把输出端从逐 token 自回归换成并行解码：在动作 token 之间去掉因果掩码，改用双向注意力让动作位置互相可见，视觉和文本 token 仍按原方式参与。输出层也从逐 token 解码换成一个 MLP 动作头，直接回归出连续动作值，用 L1 目标训练。它同时改了三处：并行解码、连续动作表示、L1 回归；离散动作 token 被连续值取代，一个 action chunk 在单次前向里一起生成。PD-VLA 走的也是并行解码，但不改网络结构、不重新训练：它把自回归解码看成一组非线性方程，用 Jacobi 式不动点迭代并行求解，迭代收敛后得到与逐 token 解码一致的结果。

两类方法各有代价与收益。OpenVLA-OFT 换了输出头和解码方式，需要微调才能使用；好处是连续动作头同时去掉了离散化误差。PD-VLA 免训练、可叠加在已有模型上，但加速取决于迭代收敛速度，收敛慢时实际收益会下降。

## 少步 / 一步生成

flow 和 diffusion 把动作生成建模成沿一条轨迹从噪声到动作的过程，推理时要数值积分这条轨迹。步数多则精度稳但慢，这一段的成本主要花在步数上。

flow matching 是这条路线的一种典型建模：学习一个把噪声搬向动作的向量场，推理时积分这条向量场，十步量级就能生成一个连续动作块，比多步 diffusion 快得多。Consistency Policy 更进一步从步数入手：先训练一个多步的 diffusion 策略当 teacher，再蒸馏出一个 consistency 模型，让它在同一条 ODE 轨迹的不同点上预测同一个终点，于是推理可以一步或少数几步直接落到动作。

这条路线的前提是要先有一个多步的 teacher 模型，蒸馏是额外的一轮训练。收益是推理步数从几十降到个位数甚至一步，延迟随步数成比例下降；风险是步数压到极致时，动作的精度和多样性可能受损。

## 动作 token 化

把连续动作离散成 token，就能复用语言模型成熟的自回归解码路径。但逐维均匀分箱这种朴素离散会产生很长的 token 序列，自回归解码要逐个解出，序列越长越慢。

FAST 换一种离散方式：先对一个动作块做离散余弦变换（DCT）转到频域，量化系数后再用字节对编码（BPE）压缩，得到的 token 数比逐维分箱少得多。π0-FAST 就是把 π0 的动作改用 FAST token，采用自回归解码，而不是 flow matching。

token 数减少直接缩短了自回归需要执行的步数，训练成本也更低。但它仍然是自回归解码，串行性没有被消除，只是序列变短，所以加速上限不如并行解码或一步生成；另外 DCT 与 BPE 是一组确定性编解码，部署时需要配套的解码把 token 还原成动作。

## 投机解码

投机解码不改大模型的输出，只改计算方式：让一个小的 draft 模型先自回归地快速草拟一串动作 token，大模型再用一次前向并行验证这串草稿，接受其中正确的前缀，只在第一个分歧处回退重算。标准投机解码要求 draft token 与大模型预测逐 token 完全相等才接受，因此最终输出与大模型单独解码严格一致。

直接把这套标准流程迁移到 VLA 上提速有限，因为动作 token 的接受率不高。Spec-VLA 利用动作被离散成 bin 后 token 序号之差即反映动作幅度之差这一点，采用松弛接受：不再要求逐 token 相等，而是把接受区间从单个 bin 放宽到相邻若干个 bin，draft token 落在阈值范围内就接受，接受率因此提高。松弛接受不再保证输出与大模型单独解码严格一致，而是允许在动作空间的容差范围内偏离，用一点动作精度换更高的接受率。

代价是要多维护一个 draft 模型，加速幅度取决于 draft 的质量和接受率。松弛的阈值取多大，直接决定接受率和动作精度之间的平衡，需要按任务权衡。

## 机制对比

四条机制改的是动作生成这一段的不同环节，训练前提和主要风险也不同：

| 机制 | 如何压缩动作生成 | 训练或前提依赖 | 主要风险 |
| --- | --- | --- | --- |
| 并行动作解码 | 去掉 token 间的串行依赖，一次前向生成整段 | OpenVLA-OFT 要微调出连续动作头；PD-VLA 免训练但靠迭代收敛 | 动作头欠拟合或迭代不收敛时，动作质量下降 |
| 少步 / 一步生成 | 把多步采样压到少数步或一步 | 需要先有多步 teacher，再蒸馏 | 步数压到极致时损失精度或多样性 |
| 动作 token 化 | 减少要自回归解码的 token 数 | 仍是自回归训练，需配套 DCT 与 BPE 编解码 | 保留串行解码，加速上限低于并行解码与一步生成 |
| 投机解码 | 小模型草拟、大模型并行验证 | 需额外维护一个 draft 模型 | 接受率低则加速有限；松弛接受放弃了与大模型解码的严格一致，用动作精度换接受率 |

并行动作解码和少步 / 一步生成直接去掉串行解码或迭代采样这两个维度，提速幅度最大，但都要改动训练或迭代过程；动作 token 化和投机解码在保留原有解码范式的前提下提速，改动小、易叠加，加速上限相对有限。具体选哪一类，还要看是否允许重新训练，以及能否接受动作质量上的细微变化。
