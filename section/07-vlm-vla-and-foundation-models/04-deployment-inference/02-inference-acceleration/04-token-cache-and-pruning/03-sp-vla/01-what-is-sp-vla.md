# SP-VLA 是什么

SP-VLA 是 token 剪枝路线上的免训练推理优化，把连续控制里的时序冗余和空间冗余合到一个框架里同时处理。时序上，闭环操作的动作序列里存在大量平滑过渡步，相邻动作差别很小，用一个轻量回归器按历史外推就能得到下一步，不必每步都跑完整 VLA 前向。空间上，单帧图像里背景和远离操作点的区域产生的视觉 token 对当前动作贡献很小，进语言模型前先剪掉能直接减少 token 数。两套机制都不引入新参数、不动基座权重，作为一层优化叠在 OpenVLA、CogACT 这类已有 VLA 上。

## 本节目标

理解 SP-VLA 在 token 剪枝路线里的定位、它与单帧剪枝和跨帧复用的差别、时序与空间两类冗余各由哪个模块处理、以什么为基座，以及加速的整体量级。

## 在 token 剪枝路线里的定位

FastV、SparseVLM 这类方法在单帧之内按重要性丢弃视觉 token，收益来自减少语言模型要处理的 token 数。VLA-Cache 走另一条路，跨控制步复用静态 token 已算出的 KV，收益来自帧间时序冗余。SP-VLA 把剪枝和调度叠在一起：剪枝这一半仍是单帧内按重要性选 token，但判据用注意力加边缘的联合打分，且剪枝比例随动作速度自适应；调度这一半利用时序冗余，直接跳过一部分完整前向。

和只做剪枝的方法相比，SP-VLA 多出的调度模块是主要加速来源。VLA 的动作输出只有约 7 个 token，单帧剪枝能省下的解码长度本就有限，剪枝过度又会破坏空间保真、影响精确操作。跳过整次前向省下的是整次约 7B 前向的计算，量级远大于剪几十个视觉 token。消融里单独开调度能到 1.27× 且精度仅降约 1%，单独开剪枝的加速更小、精度更敏感（论文报告）。

## 时序冗余：模型调度

调度模块按末端平移把动作分成两类。deliberative 动作对应抓取、转向、对准这类精细步，末端在竖直方向有明显位移或方向变化，交给完整 VLA 生成。intuitive 动作对应平滑过渡步，末端主要在水平面上匀速移动，用一个 Ridge 回归器对最近几步的动作按时间外推得到下一步。为避免连续外推积累误差，调度还要求动作缓冲里由 VLA 真正生成的动作占比足够高，才允许走外推路径。

## 空间冗余：token 剪枝

剪枝模块在视觉 token 进语言模型前按两类信号打分再合并。semantic 分数取自 SigLIP 视觉编码器末层的注意力，累积注意力高的 token 判为重要。spatial 分数来自 Canny 边缘检测：物体轮廓所在的 patch 对应的 token 一律保留，补上纯注意力容易漏掉的边缘细节。两组索引按原始顺序取并集，保留 token 的相对位置不变，因为 VLA 对 token 的相对位置敏感。剪枝比例不固定，随当前动作速度线性调整，低速精细操作阶段关闭剪枝以保精度。

## 免训练与基座

SP-VLA 在 LIBERO 上以 OpenVLA（7B，Prismatic 双视觉主干加 Llama-2）为基座，在 SimplerEnv 上以带 diffusion 动作头的 CogACT 为基座，说明它对不同动作头都适用。免训练指调度与剪枝逻辑不引入新参数，基座权重不动。公开仓库 [ChildTang/SP-VLA](https://github.com/ChildTang/SP-VLA) 目前只包含 OpenVLA/LIBERO 这条可运行路径，CogACT/SimplerEnv 的加速实现未随仓库发布。

## 加速的整体量级

LIBERO 四套件（OpenVLA 基座）上 SP-VLA 分无损、激进两档，SimplerEnv（CogACT 基座）按三种设定报告（论文报告，精度在 A100 40GB、延迟在 RTX 4090）：

| 基座与设定 | 成功率 | 加速 |
| --- | --- | --- |
| OpenVLA / LIBERO 无损档 | 74.90%（基线 74.60%） | 1.35×，FLOPs 降至 73.64% |
| OpenVLA / LIBERO 激进档 | 71.90% | 1.50×，FLOPs 降至 66.51% |
| CogACT / SimplerEnv 视觉匹配 | 75.05%（基线 74.80%） | 2.15× |
| CogACT / SimplerEnv 视觉聚合 | 65.16%（基线 61.30%） | 2.09× |
| CogACT / SimplerEnv WidowX | 57.29%（基线 51.30%） | 2.41× |

摘要口径的 SimplerEnv 2.4× 对应 WidowX 这组最优设定。RTX 4090 上 CogACT 单步延迟从约 0.27s 降到约 0.13s、控制频率约 3.8Hz 升到约 8.06Hz；真机 Franka 端到端约 2.5×、成功率仅降 1 个百分点。逐项数字、消融链与源码实现在[模型调度源码](03-model-scheduling.md)和[token 剪枝源码](04-token-pruning.md)展开。

## 本页小结

- SP-VLA 是 token 剪枝路线的免训练优化，同时处理时序冗余（模型调度）和空间冗余（token 剪枝），不改结构、不重训。
- 调度是主要加速来源：跳过整次约 7B 前向省下的计算，量级远大于单帧剪几十个视觉 token；消融里单独调度 1.27×、精度降约 1%。
- 剪枝按 SigLIP 注意力和 Canny 边缘联合打分选 token，取并集且保序，剪枝比例随速度自适应、低速关闭。
- 基座为 OpenVLA（LIBERO）与 CogACT（SimplerEnv）；LIBERO 上 1.35×–1.50×、SimplerEnv 上 2.09×–2.41×，公开仓库只含 OpenVLA/LIBERO 可跑路径。
