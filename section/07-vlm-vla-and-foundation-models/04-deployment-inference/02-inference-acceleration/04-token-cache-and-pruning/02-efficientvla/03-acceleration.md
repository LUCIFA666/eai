# 三条加速策略

EfficientVLA 的加速来自三条策略：语言模块的层剪枝压缩显存受限区的权重量，视觉 token 剪枝减少进入语言模块的序列长度，扩散动作头的特征缓存跳过去噪步之间的重复计算。三者都在推理期用一次前向里的隐藏态、注意力和固定调度完成，没有需要训练的参数。

## 本节目标

理解三条策略各自的打分方式与关键参数：层重要度如何量化并做非连续剪枝、视觉 token 如何在任务相关性与多样性之间分配、扩散特征如何按固定间隔缓存，以及这些参数组合出的加速数字。

## 语言模块层剪枝

层剪枝针对的是语言模块的层间冗余。一个 Transformer 层对隐藏态做的是残差更新 $\boldsymbol{x}^{(\ell+1)} = \boldsymbol{x}^{(\ell)} + f(\boldsymbol{x}^{(\ell)})$，如果 $f$ 的改动很小，输出就与输入高度相似，这一层的作用有限。EfficientVLA 用输入输出的余弦相似度来量化每层的重要度，在一批代表性样本 $\mathcal{D}$ 和全部 token 位置上取平均：

$$
I^{(\ell)} = 1 - \frac{1}{|\mathcal{D}|} \sum_{i=1}^{|\mathcal{D}|} \left( \frac{1}{L} \sum_{j=1}^{L} \frac{\boldsymbol{x}^{(\ell)}_{i,j} \cdot \boldsymbol{x}^{(\ell+1)}_{i,j}}{\|\boldsymbol{x}^{(\ell)}_{i,j}\|_2 \, \|\boldsymbol{x}^{(\ell+1)}_{i,j}\|_2} \right)
$$

相似度越高，重要度 $I^{(\ell)}$ 越低。把 32 层按 $I^{(\ell)}$ 升序排列，取最靠前的 $n$ 层移除。这里的剪枝是非连续的：被剪的层按重要度挑选，不要求是一段相邻的层，冗余分散在哪些层就剪除哪些层。主结果保留 22 层或 28 层，对应剪掉 10 层或 4 层。这一步只需在样本上离线统计一次相似度，不更新权重。

层剪枝之外，EfficientVLA 对保留下来的每一层再按 PruneNet 做一次 MLP 压缩，把 MLP 权重按 25% 稀疏度裁剪。组件消融里，只做剪层会让成功率降到 85.7%，补上 MLP 压缩后回到 92.3%，说明两者配合能在缩减权重的同时守住精度（论文报告）。

## 视觉 token 剪枝

视觉 token 剪枝要从 256 个 token 里选出一个大小为 $K_{final}$ 的紧凑子集，兼顾任务相关性与信息覆盖。相关性由 cross-attention 给出：对每个视觉 token $v_i$，取它对 $L_{ctx}$ 个文本 token 的注意力，先在 $H$ 个注意力头上平均，再对文本 token 求和，得到原始相关分，随后归一化到 $[0,1]$：

$$
r_i = \sum_{j=1}^{L_{ctx}} \left( \frac{1}{H} \sum_{h=1}^{H} A^{(h)}_{i,j} \right)
$$

选择分三步。先取相关分最高的 $K_{key}$ 个 token 作为核心集 $V_{key}$，无条件保留，主结果里 $K_{key}=4$。再从剩余 token 里补足 $K_{aug}=K_{final}-K_{key}$ 个，按比例 $\alpha$ 分成两部分：$\lfloor \alpha \cdot K_{aug} \rfloor$ 个继续按相关分取，剩下的按多样性取。多样性以与核心集的最大余弦相似度的补来衡量，值越大表示与已选 token 越不同：

$$
\text{Diversity}(v_j, V_{key}) = 1 - \max_{v_k \in V_{key}} \frac{v_j \cdot v_k}{\|v_j\|_2 \, \|v_k\|_2}
$$

最终子集是 $V_{key}$、任务驱动集、多样性集三者的并。主结果里 $\alpha=50\%$，即增补配额的一半用于保持相关性、一半用于保持多样性。多样性这一项是关键：只按相关分取会留下彼此相似的高分 token，多样性项把其余区域的视觉信息补回。对照随机保留 112 个 token 的做法，平均成功率会降到 20.9%，而带打分的选择保持在基线水平（论文报告）。

token 筛减从第 2 层 Transformer 开始，前两层仍处理完整 256 个 token，之后的层只在紧凑子集上计算。视觉 token 从 256 减到 56，这一段序列长度降约 78%。

## 扩散动作头特征缓存

扩散动作头在每个去噪步 $t$ 的 DiT 块里，先算自注意力 $\mathbf{h}_t^{\text{attn}} = \text{Self-Attn}(\mathbf{z}_t)$，再算 $\mathbf{h}_t^{\text{mlp}} = \text{MLP}(\mathbf{h}_t^{\text{attn}} + \mathbf{z}_t)$。相邻去噪步的这两组特征变化很小，即 $\mathbf{h}_t^{\text{module}} \approx \mathbf{h}_{t-1}^{\text{module}}$，重算基本得到相同结果。

缓存按固定间隔 $N$ 调度。在起始步和满足 $t \bmod N = 0$ 的步上，正常计算 attn 与 MLP 特征并写入缓存；其余步跳过 Self-Attn 和 MLP，直接读取最近一次缓存的特征。这样每 $N$ 步里有 $N-1$ 步省去了这两个模块的计算。主结果取 $N=5$，10 步去噪里只有约 2 步真正重算。cache interval 从 1 增到 5，pick coke can 的单步时间从 0.2342s 降到 0.1909s；FLOPs 几乎不变，因为缓存节省的是被跳过步的执行，而非改变单步的计算量（论文报告）。

## 可调参数

三条策略的参数与主结果取值如下：

| 参数 | 含义 | 主结果取值 |
| --- | --- | --- |
| 保留层数 L | 语言模块剪枝后保留的层数（原 32 层） | 22 或 28 |
| MLP 稀疏度 | 保留层的 MLP 权重按 PruneNet 裁剪的比例 | 25% |
| $K_{final}$ | 保留的视觉 token 数（原 256） | 56 或 112 |
| $K_{key}$ | 无条件保留的核心 token 数 | 4 |
| $\alpha$ | 增补配额中任务驱动的占比 | 50% |
| 起始层 | 从第几层 Transformer 开始筛 token | 第 2 层 |
| cache interval N | 每 N 步去噪重算一次特征 | 5 |

L 和 $K_{final}$ 是加速与精度的主调节量：层数越少、token 越少，FLOPs 与延迟越低，精度损失也随之增大。

## 加速数字与规模化

四组 L 与 $K_{final}$ 的组合在 SIMPLER Visual Matching 上的表现如下（论文报告）：

| 配置 | 平均成功率 | FLOPs | 加速 | 总参 (B) |
| --- | --- | --- | --- | --- |
| L=28, T=112 | 76.4% | 45.1% | 1.59× | 5.87 |
| L=28, T=56 | 75.5% | 32.9% | 1.71× | 5.87 |
| L=22, T=112 | 75.0% | 38.2% | 1.78× | 4.86 |
| L=22, T=56 | 74.2% | 28.9% | 1.93× | 4.86 |

最激进的 L=22、T=56 把 FLOPs 降到基线的 28.9%、加速 1.93×，成功率 74.2% 对基线 74.8%，只差 0.6 个百分点。分到模块上，语言模块参数从 6738.9M 降到 3971.1M（降 41%），视觉 token 从 256 降到 56（降 78%），去噪重算步从 10 降到约 2（降 80%）；语言模块单步延迟从 134.5ms 降到 58.9ms（降 56%），动作模块从 51.5ms 降到 26.2ms（降 49%）。

加速幅度随动作头增大而更明显。三种 CogACT 规模下保持 L=22、T=56（论文报告）：

| 模型 | 动作头参数 | 基线单步 (s) | EfficientVLA 单步 (s) | 基线成功率 | EfficientVLA 成功率 |
| --- | --- | --- | --- | --- | --- |
| CogACT-Small | 13M | 0.2156 | 0.1173 | 73.3% | 72.6% |
| CogACT-Base | 89M | 0.2342 | 0.1213 | 74.8% | 74.2% |
| CogACT-Large | 308M | 0.2628 | 0.1312 | 76.7% | 76.1% |

动作头参数越大，去噪的单步计算越重，特征缓存节省的越多，CogACT-Large 上加速达到约 2.0×，而成功率只从 76.7% 降到 76.1%。

## 本页小结

- 层剪枝按输入输出余弦相似度定义层重要度，非连续地剪掉最冗余的层，保留层再按 25% 稀疏度压缩 MLP；主结果保留 22 或 28 层。
- 视觉 token 剪枝用 cross-attention 打任务相关分，先保 $K_{key}=4$ 个核心 token，再按 $\alpha=50\%$ 在相关性与多样性之间分配增补，从第 2 层起把 256 个 token 减到 56 或 112。
- 特征缓存利用相邻去噪步的高相似度，按间隔 $N=5$ 复用 attn 与 MLP 特征，每 5 步只重算约 1 步。
- L=22、T=56 时 FLOPs 降到基线的 28.9%、加速 1.93×，成功率仅降 0.6 个百分点；动作头越大加速越明显，CogACT-Large 达约 2.0×（论文报告）。
