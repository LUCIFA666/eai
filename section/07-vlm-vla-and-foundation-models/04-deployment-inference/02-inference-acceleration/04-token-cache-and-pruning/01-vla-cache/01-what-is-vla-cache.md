# VLA-Cache 是什么

VLA-Cache 是 token cache 路线上的免训练推理优化：在 OpenVLA 这类自回归 VLA 上，跨控制步复用几乎没变的视觉 token 的 key-value，只重算变化明显或任务相关的 token。它不改模型结构、不重新训练，作为一层优化叠加在已有权重上。收益来自闭环操作的时序连续性：相邻相机帧高度重叠，大量视觉 token 在帧间基本不动，重新计算只会得到几乎相同的 KV。

## 本节目标

理解 VLA-Cache 在 token cache 路线里的定位、它与单帧 token 剪枝的差别、复用与重算如何划分、以什么为基座，以及加速的整体量级。

## 在 token cache 路线里的定位

标准 KV cache 是自回归解码的常规优化：每生成一个新 token 都要对之前所有 token 做注意力，历史 token 的 key-value 在后续步骤里不再改变，缓存下来即可跳过重算。它消去的是单次解码内部、序列方向上的重复，不处理视觉流的冗余。VLA 逐帧推理时把上一帧的视觉编码丢弃、当前帧从头重算全部视觉 token，帧间重叠的那部分计算就被反复执行。

VLA-Cache 把复用从一次解码内部扩展到控制步之间：静态视觉 token 的 KV 不仅在一次解码内可复用，还能跨帧复用。这与 FastV、SparseVLM 的思路方向不同。后两者是单帧 token 剪枝与合并，在一帧图像之内丢弃或合并 token；VLA-Cache 保留全部 token，但跨帧复用其中静态部分的 KV。在 VLA 上直接套用单帧剪枝收益有限：VLA 的动作输出只有约 7 个 token，远短于 VLM 的长文本输出，剪枝减少的解码长度本就不多，而丢弃 token 又破坏空间保真，影响精确操作。LIBERO 上 SparseVLM 的单步延迟反而从 51.91ms 升到 83.39ms、平均成功率从 75.0% 降到 64.7%，FastV 延迟基本持平（53.28ms）、成功率 73.3%，都不及 VLA-Cache 的 31.83ms 与 74.7%（论文报告）。

## 复用什么，重算什么

复用的判据是两层：先看视觉是否静态，再看是否任务相关。只按静态复用并不安全。夹爪、目标物体这些区域在像素上可能几乎不变，但语义上随操作推进而变化，对动作精度关键。把所有静态 token 一律复用，会让 LIBERO-Spatial 成功率从 OpenVLA 的 84.4% 降到 74.2%。

VLA-Cache 因此在静态集之外再做一次任务相关过滤：从解码器的 text-to-vision 交叉注意力聚合出每个视觉 token 的任务相关度，把任务相关的 token 从复用集里剔除，留给当前步重算。这条过滤把成功率从 74.2% 恢复到 82.6%。最终的复用集是静态且非任务相关的 token，其余 token 全部重算，以对齐最新环境状态。

## 免训练与基座

VLA-Cache 主要在 OpenVLA（7B，Prismatic/Llama-2 主干）上实现，并在 OpenVLA-OFT 和带 diffusion 动作头的 CogAct 上验证过，说明它对不同动作头都适用。免训练指的是选择与复用逻辑不引入新参数，基座权重本身不动。KV 的实际替换要改动注意力前向：据主仓库 `README_VLA_Cache.md`，这一步由配套改动的 `transformers` 完成，运行时需装该改动版本。

## 加速的整体量级

LIBERO 四个任务套件上，VLA-Cache 相对 OpenVLA 的效率收益如下（论文报告，RTX 4090）：

| 指标 | OpenVLA | + VLA-Cache | 变化 |
| --- | --- | --- | --- |
| 平均成功率 | 75.0% | 74.7% | −0.3 |
| FLOPs | 1.864T | 1.355T | 约 −27% |
| 单步延迟 | 51.91ms | 31.83ms | 约 1.63× |
| 控制频率 | 4.23Hz | 4.59Hz | 约 +8.5% |

在已经做过并行解码优化的 OpenVLA-OFT 上仍有叠加收益：控制频率从 65.10Hz 提到 78.98Hz，成功率 96.8% 到 97.4%。论文摘要口径的整体量级是最高约 1.7× 延迟加速、约 15% 控制频率提升，且成功率基本不降。逐项数字与消融链在[跨帧 token 缓存](03-token-caching.md)展开。

## 本页小结

- VLA-Cache 是 token cache 路线的免训练优化：跨控制步复用静态视觉 token 的 KV，只重算变化或任务相关的 token，不改结构、不重训。
- 与 FastV、SparseVLM 的单帧 token 剪枝方向不同，它跨帧复用而非帧内丢弃；单帧剪枝在动作输出仅约 7 token 的 VLA 上收益有限，还因破坏空间保真而降精度。
- 复用集是静态且非任务相关的 token：只按静态复用会把 LIBERO-Spatial 成功率从 84.4% 降到 74.2%，任务相关过滤恢复到 82.6%。
- 基座为 OpenVLA，并在 OpenVLA-OFT、CogAct 上验证；LIBERO 上 FLOPs 降约 27%、延迟约 1.63×、成功率仅降 0.3 个百分点。
