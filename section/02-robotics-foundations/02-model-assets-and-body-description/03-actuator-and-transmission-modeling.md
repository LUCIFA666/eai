# 执行器与传动建模

## 本章概述

对于机器人而言，策略模型输出的动作命令并不会直接作用于机械结构，而是需要经过控制器发送给执行器（Actuator），再由执行器驱动机器人完成实际运动。因此，执行器不仅是机器人中的一种硬件设备，更是连接软件世界与物理世界的重要接口。

在具身智能系统中，无论策略模型多么先进，其最终能够执行的动作都受到执行器能力的限制。例如，有些机器人支持关节位置控制，有些支持速度控制，还有一些能够进行力矩控制或阻抗控制；不同机器人能够输出的最大速度、最大力矩以及控制频率也各不相同。这意味着，同样的策略模型部署到不同机器人平台时，能够使用的动作空间和控制接口可能完全不同。

除了执行器本身，机器人还包含减速器、传动机构、编码器、制动器以及零位校准等组成部分，它们共同决定了机器人关节的运动精度、输出能力以及控制性能。在机器人模型和仿真环境中，这些部件通常不会单独建模，而是通过一系列动力学参数进行抽象描述。

本章将介绍执行器及传动系统在机器人中的作用，说明常见执行机构的基本组成，分析执行器能力如何影响控制模式，并解释机器人模型和控制接口中常见动力学参数的含义。同时讨论仿真环境与真实机器人在控制接口上的差异，帮助读者理解哪些执行器建模信息会直接影响具身智能策略训练和真实机器人部署。本章不涉及电机控制算法、电路设计或驱动器硬件实现，而重点关注软件建模和接口设计层面的内容。

## 执行器：连接控制命令与物理运动的接口

在机器人控制系统中，执行器（Actuator）位于控制器与机器人机械结构之间，是动作命令真正作用到物理世界的执行环节。

一条典型的控制链路可以表示为：

```text
Policy
    │
Action
    │
Controller
    │
Actuator
    │
Robot Joint
    │
Physical Motion
```

策略模型输出的动作，无论是关节角度、关节速度还是力矩，都需要经过执行器才能转化为真实的机械运动。因此，从软件系统角度来看，执行器不仅是一种硬件设备，更代表机器人能够接受什么样的控制命令，以及这些命令最终能够产生怎样的运动效果。

对于具身智能而言，策略模型通常不会直接关心电机型号或驱动器品牌，而更关注执行器能够提供哪些控制接口、支持哪些动作空间，以及动作命令能够达到怎样的精度和响应速度。因此，执行器可以理解为机器人动作接口在物理世界中的最终实现。

## 执行器与传动系统的组成

机器人关节通常并不是由单一部件构成，而是由多个功能模块共同组成一个完整的驱动系统。这些模块虽然属于硬件结构，但会直接影响机器人控制接口和运动性能，因此在机器人建模中具有重要意义。

### 电机

电机是执行器中最核心的动力来源，其作用是将电能转换为机械旋转运动，为机器人关节提供驱动力。

不同类型的机器人可能采用伺服电机、无刷直流电机、直驱电机或其他驱动形式，但对于机器人软件而言，更重要的是电机能够输出的最大转速、最大力矩以及控制方式，而不是具体的硬件型号。

### 减速器

电机通常具有较高转速而较低输出力矩，因此机器人关节一般需要通过减速器降低转速、提高输出力矩。

减速器不仅决定机器人能够输出多大的关节力矩，还会影响关节运动精度、反向间隙以及系统刚性。

在机器人模型中，减速器通常通过减速比（Gear Ratio）进行描述，而不是对其内部机械结构进行建模。

### 传动链

传动链用于连接电机与机器人关节，将电机输出的运动传递到实际关节。

不同机器人可能采用：

- 齿轮传动
- 谐波减速器
- 同步带传动
- 丝杠传动
- 钢索传动
- 连杆机构

不同传动方式会带来不同的效率、刚度、摩擦以及运动精度，因此也会影响机器人动力学模型和控制效果。

### 编码器

编码器用于测量关节当前的位置和运动状态，是机器人状态反馈的重要来源。

控制器通常依赖编码器获取：

- 当前关节角度
- 当前关节速度
- 零位参考
- 运动方向

Robot State 中的大部分关节状态数据，实际上都来自编码器反馈。

### 制动器

部分机器人关节配有制动器，用于在机器人断电或停止控制时锁定关节位置。

例如，人形机器人、重载机械臂以及升降机构通常会采用机械制动器，以防止机器人在失电后发生意外运动。

制动器虽然通常不会直接参与策略控制，但会影响机器人启动、停止以及安全控制流程。

### 零位

每个机器人关节都需要定义统一的零位（Zero Position 或 Home Position）。

零位既是机器人初始化时的重要参考，也是关节位置计算和运动规划的基准。

机器人每次启动后，通常需要完成回零（Homing）或零点校准，以保证控制器、机器人模型以及编码器之间保持一致的坐标参考。

## 执行器能力与控制模式

虽然机器人控制系统通常提供统一的动作接口，但不同执行器能够支持的控制模式并不相同，因此机器人能够执行的动作空间也会受到执行器能力的限制。

最常见的控制方式是**位置控制（Position Control）**。控制器接收目标关节位置，执行器负责驱动关节运动到指定位置。这是工业机械臂和协作机器人最常见的控制模式，也是许多具身智能策略默认采用的动作形式。

另一种常见方式是**速度控制（Velocity Control）**。在这种模式下，策略输出关节目标速度，由执行器持续调节关节运动速度。移动机器人底盘、轮式机器人以及连续旋转关节通常大量采用速度控制。

对于部分高性能机器人，还支持**力矩控制（Torque Control）**。此时策略输出的是目标关节力矩，而执行器负责按照指定力矩驱动机器人运动。力矩控制能够实现更加自然的接触控制，因此在强化学习、人形机器人和动态控制研究中应用较多，但对执行器性能和控制器实时性要求也更高。

此外，还有越来越多机器人支持**阻抗控制（Impedance Control）**。阻抗控制并不是单纯控制位置或力矩，而是通过设定机器人与环境之间的力学关系，使机器人具有一定柔顺性。例如，当机械臂接触桌面时，不会继续施加过大的压力，而是能够根据外部接触自动调整运动。

需要注意的是，并不是所有机器人都开放这些控制模式。很多工业机器人仅允许用户发送目标位置，而底层速度环和力矩环完全封装在厂商控制器内部；也有一些科研平台开放速度控制和力矩控制接口，方便研究者开展先进控制算法实验。因此，在部署策略之前，必须确认机器人实际支持哪些控制模式，而不能仅依据仿真环境中的接口设计。

## 模型与控制接口中的关键参数

在机器人模型和控制接口中，虽然不会直接描述电机内部结构，但通常会通过一系列动力学参数抽象执行器和传动系统的特性。这些参数不仅影响物理仿真效果，也会影响控制器的行为。

**Gear Ratio（减速比）** 用于描述电机与关节之间的传动比例，它决定了电机输出与关节运动之间的对应关系，也影响机器人能够输出的速度和力矩。

**Motor Limit（电机限制）** 描述电机能够提供的最大能力，例如最大转速、最大输出电流或最大力矩。这些限制决定了机器人实际能够执行的动作范围。

**Effort Limit（最大驱动力）** 表示关节允许输出的最大力或最大力矩。在机器人模型中，它通常用于限制控制器输出，防止仿真或真实机器人产生超出安全范围的控制命令。

**Velocity Limit（速度限制）** 定义关节允许达到的最大运动速度。控制器通常会根据该参数自动限制关节运动，避免高速运动带来的安全风险。

**Armature（转动惯量）** 用于描述执行器内部旋转部件的惯性，它会影响机器人动力学响应。在 MuJoCo 等物理引擎中，合理设置 Armature 可以提高仿真稳定性，使机器人运动更加接近真实系统。

**Damping（阻尼）** 用于描述关节运动过程中受到的阻尼作用。适当的阻尼能够抑制振荡，提高控制稳定性；阻尼过小则可能导致机器人出现持续摆动。

**Friction（摩擦）** 描述关节和传动机构中的摩擦效应。真实机器人不可避免地存在静摩擦和动摩擦，而仿真中通常需要通过 Friction 参数进行近似建模，以改善机器人低速运动和接触控制的真实性。

这些参数虽然不会直接作为策略模型的输入，但会影响机器人动力学行为和控制效果，因此在仿真建模、控制调试以及 Sim-to-Real 迁移过程中具有重要意义。

## 仿真与真机控制接口的差异

现代机器人仿真平台通常提供较高自由度的控制接口。例如，在 MuJoCo、Isaac Sim 或 Gazebo 中，开发者可以直接向机器人发送位置、速度或力矩命令，并实时获取完整的关节状态。这种灵活性使研究者能够方便地验证不同控制算法和策略模型。

然而，真实机器人并不一定开放同样的接口。

许多工业机器人为了保证安全性和设备可靠性，只允许用户发送目标位置或末端位姿，而底层的速度控制、力矩控制以及伺服环均由厂商控制器封装实现，用户无法直接访问。这意味着在仿真中基于力矩控制训练得到的策略，部署到真实机器人时可能无法直接使用。

此外，不同机器人厂商开放的接口粒度也存在明显差异。有些机器人支持高频关节控制，允许用户以数百赫兹甚至上千赫兹发送控制命令；有些机器人则仅支持较低频率的运动指令，由控制器负责完成轨迹插值。对于策略模型而言，这意味着动作更新频率、动作空间以及控制延迟都会发生变化。

因此，在进行仿真训练和真实部署时，应始终以真实机器人实际提供的控制接口为约束，避免依赖仿真环境中特有而真机无法支持的控制能力。只有充分考虑执行器和控制器的实际限制，才能提高策略迁移的成功率和系统的工程可用性。

## 本章建议掌握的内容

本章不要求读者掌握电机控制原理、驱动器设计或控制电路，而是重点理解执行器建模对具身智能系统的影响。

读者应能够认识到执行器不仅是机器人中的一种硬件设备，更是软件控制命令进入物理世界的关键接口；理解电机、减速器、传动链、编码器、制动器以及零位等组成部分分别承担的作用，并知道它们如何共同影响机器人运动能力。

同时，应了解位置控制、速度控制、力矩控制和阻抗控制等不同控制模式之间的区别，理解执行器能力决定了机器人实际能够开放哪些动作接口，而策略模型必须适配这些能力。

此外，还应能够阅读机器人模型中的 Gear Ratio、Effort Limit、Velocity Limit、Armature、Damping、Friction 等关键参数，知道它们虽然属于动力学建模信息，却会直接影响仿真效果、控制性能以及策略迁移。

最后，应建立仿真与真机接口并不完全一致的认识，在设计控制系统和训练策略时始终以真实机器人支持的控制模式和接口能力为基础，而不是简单依赖仿真平台提供的全部功能。

## 本章小结

执行器是机器人控制系统中连接软件命令与物理运动的关键环节，它决定了策略输出如何最终转化为真实机器人动作。一个完整的执行器系统通常由电机、减速器、传动链、编码器、制动器和零位校准等部分组成，它们共同影响机器人的运动能力、控制精度和状态反馈。

不同执行器支持的位置控制、速度控制、力矩控制和阻抗控制等控制模式各不相同，因此机器人能够开放的动作接口也存在差异。与此同时，Gear Ratio、Effort Limit、Velocity Limit、Armature、Damping 和 Friction 等动力学参数虽然属于模型配置，却会直接影响仿真真实性和控制性能，也是进行机器人建模和策略部署时需要重点关注的内容。

在工程实践中，仿真平台通常提供更加开放和灵活的控制接口，而真实机器人受到安全策略和厂商控制器的限制，未必支持相同的控制模式。因此，在具身智能系统开发过程中，应充分考虑执行器能力和控制接口的实际约束，使策略设计、仿真验证和真机部署保持一致，为实现可靠的跨平台迁移奠定基础。
