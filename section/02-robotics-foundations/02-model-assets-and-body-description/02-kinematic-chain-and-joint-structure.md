# 运动链与关节结构

## 本章概述

机器人之所以能够完成抓取、搬运、行走等复杂动作，本质上是因为多个刚性结构通过不同类型的关节连接起来，并由执行器驱动形成了一条完整的运动链（Kinematic Chain）。无论是六自由度机械臂、移动操作机器人、四足机器人，还是人形机器人，都可以抽象为由 **Link（连杆）**、**Joint（关节）** 和 **Actuator（执行器）** 组成的层级结构。

对于机器人软件系统而言，运动链不仅决定机器人能够如何运动，还决定了状态数据如何组织、动作命令如何发送、控制器如何驱动以及数据集如何记录。因此，在阅读机器人模型、调试控制程序或训练具身智能策略时，理解运动链的组成方式比掌握复杂的运动学推导更加重要。

本章将介绍 Link、Joint、Actuator 和自由度（Degree of Freedom，DoF）之间的关系，说明不同关节类型对机器人状态和控制接口的影响，解释运动链是如何通过父子连接关系建立起来的，并重点分析关节名称、关节顺序以及特殊关节在工程系统中的作用。需要说明的是，本章主要关注机器人模型和软件接口，不展开 DH 参数、运动学求解或动力学推导等理论内容。

## Link、Joint、Actuator 与自由度

机器人可以看作是由若干个刚性部件按照一定规则连接形成的树状结构，其中每一个组成部分都承担着不同的职责。

**Link（连杆）** 是机器人中不可发生相对形变的刚性结构，例如机械臂的各级连杆、机器人底盘、夹爪本体或相机安装支架等。Link 决定了机器人各个部件的几何形状、质量分布、惯性参数以及碰撞模型，是机器人物理结构的基本组成单元。

不同 Link 之间并不能直接发生运动，它们需要通过 **Joint（关节）** 建立连接。Joint 定义了两个 Link 之间允许发生什么样的相对运动，例如只能旋转、只能平移，或者完全固定不动。因此，Joint 描述的是机器人运动的约束关系，而不是驱动力。

真正驱动机器人运动的是 **Actuator（执行器）**。执行器通常由电机、驱动器、减速器、液压系统或气动系统组成，其作用是在控制器的指令下，为关节提供运动能力。需要注意的是，执行器通常安装在关节上，而不是安装在 Link 上，因此一个可驱动关节通常对应一个执行器。

机器人能够独立控制的运动变量数量称为 **自由度（Degree of Freedom，DoF）**。一般情况下，每一个可驱动关节对应一个自由度。例如，一个典型的六轴机械臂拥有六个可控旋转关节，因此具有六个自由度；一个移动操作机器人如果包含一个六自由度机械臂和一个二维移动底盘，则整体自由度会进一步增加。

从工程角度来看，这四者之间可以概括为如下关系：

- **Link** 描述机器人由哪些刚性部件组成；
- **Joint** 描述各个部件之间允许发生什么运动；
- **Actuator** 提供驱动能力，使关节能够按照控制命令运动；
- **Degree of Freedom（DoF）** 描述机器人能够独立控制多少个运动变量。

理解这一关系，是阅读机器人模型和理解控制接口的基础。

## 常见关节类型及其特点

不同类型的机器人关节决定了机器人能够执行哪些运动，也直接影响状态字段和控制命令的定义。在机器人模型中，最常见的关节类型包括 Revolute、Prismatic、Fixed、Continuous 和 Floating。

### Revolute Joint（旋转关节）

Revolute Joint 是机器人中最常见的一种关节类型，它允许两个 Link 围绕固定轴进行有限角度旋转。

典型的工业机械臂、协作机械臂以及人形机器人关节几乎都采用 Revolute Joint。

其状态通常包括：

- 当前关节角度（Position）
- 当前角速度（Velocity）
- 当前力矩（Effort）

控制命令一般对应目标角度、目标角速度或目标力矩。

由于 Revolute Joint 通常具有上下限，因此模型中还会定义关节角度范围、速度限制以及力矩限制。

### Prismatic Joint（移动关节）

Prismatic Joint 允许两个 Link 沿某一固定方向进行直线运动。

这种关节常见于：

- 电动滑台
- 升降机构
- 线性导轨
- 电动推杆

与 Revolute Joint 不同，它的状态变量表示的是位移而不是角度，因此控制命令通常采用长度（m 或 mm）表示。

### Fixed Joint（固定关节）

Fixed Joint 表示两个 Link 之间不存在任何相对运动。

它主要用于连接：

- 相机
- 激光雷达
- IMU
- 工具安装板
- 外壳结构

由于不存在自由度，因此 Fixed Joint 不会出现在机器人状态或动作空间中，也不需要执行器驱动。

虽然 Fixed Joint 不参与控制，但它对于机器人坐标系的建立非常重要。

### Continuous Joint（连续旋转关节）

Continuous Joint 与 Revolute Joint 类似，同样允许绕固定轴旋转，但它没有角度限制，可以进行无限旋转。

典型应用包括：

- 轮式机器人车轮
- 云台旋转机构
- 输送滚轮

由于没有上下限，因此控制器通常采用速度控制，而较少直接采用位置控制。

### Floating Joint（浮动关节）

Floating Joint 表示一个 Link 可以在三维空间自由运动。

它通常拥有六个自由度，包括：

- 三个平移自由度
- 三个旋转自由度

Floating Joint 主要用于：

- 自由漂浮机器人
- 无固定底座机器人
- 仿真中的机器人根节点

对于移动机器人或人形机器人而言，Floating Joint 常用于描述机器人整体在世界坐标系中的位姿，而不是某一个具体关节。

## Parent Link、Child Link 与运动链方向

机器人运动链本质上是一棵由 Link 和 Joint 构成的有向树。

每一个 Joint 都负责连接两个 Link：

- Parent Link（父连杆）
- Child Link（子连杆）

机器人模型通过这种父子关系逐级建立整个运动链。

例如，一个典型机械臂可以表示为：

```text
Base Link
    │
Joint1
    │
Link1
    │
Joint2
    │
Link2
    │
Joint3
    │
Link3
```

其中，Parent Link 表示运动链中更靠近机器人基座的一端，Child Link 表示更靠近机器人末端的一端。机器人控制、运动学计算以及坐标变换通常都沿着这一层级关系逐级进行。

除了父子关系之外，每个 Joint 还需要定义 **Joint Origin** 和 **Joint Axis**。

Joint Origin 用于描述关节坐标系相对于父连杆坐标系的位置和姿态，也就是说，它确定了关节安装在 Parent Link 的什么位置、采用什么方向。

Joint Axis 则定义关节实际运动的方向。例如，对于旋转关节，它表示绕哪一个坐标轴旋转；对于移动关节，它表示沿哪一个方向进行平移。

Parent Link、Child Link、Joint Origin 和 Joint Axis 共同决定了整条运动链的拓扑结构和运动方向，也是机器人运动学计算的重要基础。

## Joint Name 与 Joint Order 的重要性

对于机器人软件系统而言，关节名称（Joint Name）和关节顺序（Joint Order）是所有模块之间建立对应关系的核心依据。

每一个可运动关节都应具有唯一且固定的名称，例如：

```text
shoulder_pan_joint

shoulder_lift_joint

elbow_joint

wrist_1_joint

wrist_2_joint

wrist_3_joint
```

控制器、状态反馈、机器人模型、数据集以及策略模型都通过 Joint Name 来识别具体关节，因此名称必须保持一致。

相比关节名称，关节顺序更加容易被忽视，但影响同样巨大。

机器人状态和动作通常以数组形式进行传输，例如：

```text
Joint Position

[
0.21,
-0.34,
1.52,
...
]
```

数组本身并不知道每一个数值属于哪个关节，因此所有模块必须事先约定统一的 Joint Order。

如果模型采用：

```text
Joint1
Joint2
Joint3
```

而控制器读取顺序变成：

```text
Joint2
Joint1
Joint3
```

那么策略输出虽然数值正确，却会驱动错误的关节，导致机器人产生完全错误的动作。

因此，Joint Name 与 Joint Order 必须在以下所有模块之间保持一致：

- 机器人模型（URDF、MJCF、USD）
- Robot State
- Action
- Controller
- Robot SDK
- 数据采集程序
- 数据集
- 模型训练代码
- 真机部署程序

可以说，Joint Name 和 Joint Order 是机器人接口契约中最基础、也是最重要的一部分。

## 特殊关节及其对接口设计的影响

除了常见的旋转关节和移动关节之外，机器人模型中还存在一些特殊关节，它们虽然数量不多，但对于接口设计具有重要影响。

**Mimic Joint（联动关节）** 用于描述一个关节跟随另一个关节运动。例如，两指夹爪常常只有一个主动驱动关节，而另一侧夹爪通过 Mimic Joint 自动完成同步运动。在这种情况下，控制接口通常只需要发送一个动作，而不是分别控制两个关节。

**Passive Joint（被动关节）** 指没有执行器驱动、只能随着其他关节被动运动的关节。这类关节通常会出现在机械联动机构、弹簧机构或柔性机构中。虽然它们会出现在机器人状态中，但一般不会出现在动作命令中。

**Fixed Joint（固定关节）** 前文已经介绍，它没有任何自由度，因此既不会出现在 Robot State 中，也不会出现在 Action 中，但仍然会影响机器人坐标系和传感器安装位置。

**Gripper Joint（夹爪关节）** 则是机器人中最常见的特殊控制对象。不同机器人可能采用单关节控制、双关节控制或 Mimic Joint 实现夹爪开合，因此不同平台对夹爪动作的接口设计并不完全一致。有些系统采用一个连续数值表示夹爪开度，有些则采用离散的开闭命令，还有些会将多个夹爪关节统一封装为一个 Gripper Action。

因此，在设计机器人状态接口和动作接口时，并不是所有关节都会一一对应出现在控制命令中，而需要根据关节是否可驱动、是否联动以及是否参与控制进行合理抽象。

## 本章建议掌握的内容

本章的重点不是学习机器人运动学推导，也不是掌握 DH 参数建模方法，而是建立工程实践中阅读机器人模型和理解控制接口所需的基本认识。

读者应能够理解 Link、Joint、Actuator 和自由度之间的关系，知道机器人是如何通过父子连接关系形成完整运动链的；能够识别 Revolute、Prismatic、Fixed、Continuous 和 Floating 等常见关节类型，并理解它们对状态空间和动作空间的影响；能够阅读机器人模型中的 Parent Link、Child Link、Joint Origin 和 Joint Axis 等关键字段，理解它们如何共同决定机器人结构。

更重要的是，应充分认识到 Joint Name 和 Joint Order 在机器人软件系统中的核心作用，理解它们为什么必须在模型、状态、动作、控制器以及数据集之间保持严格一致。同时，也应了解 Mimic Joint、Passive Joint、Fixed Joint 和 Gripper Joint 等特殊关节的特点，知道它们会如何影响机器人接口设计和控制方式。

这些内容虽然属于机器人模型中的基础知识，却贯穿机器人建模、控制、数据采集、仿真和真机部署的整个开发流程，是理解后续章节的重要基础。

## 本章小结

机器人运动链由 Link、Joint 和 Actuator 共同组成，其中 Link 描述机器人刚性结构，Joint 描述各部件之间的运动约束，Actuator 为关节提供驱动能力，而自由度则反映机器人能够独立控制的运动变量数量。不同类型的关节决定了机器人能够执行的运动形式，也直接影响机器人状态字段、动作命令以及控制接口的设计。

机器人模型通过 Parent Link、Child Link、Joint Origin 和 Joint Axis 建立完整的层级结构，从而定义机器人各个关节之间的连接关系和运动方向。与此同时，Joint Name 和 Joint Order 是整个机器人软件系统共享的重要接口信息，必须在机器人模型、状态反馈、动作命令、控制器以及数据集中保持一致，否则将导致控制指令与实际关节发生错位。

此外，Mimic Joint、Passive Joint、Fixed Joint 和 Gripper Joint 等特殊关节虽然控制方式不同，但都会影响机器人接口的设计与实现。对于工程开发而言，掌握这些基础概念比复杂的运动学推导更加重要，它们构成了理解机器人模型、数据接口和控制系统的共同基础。
