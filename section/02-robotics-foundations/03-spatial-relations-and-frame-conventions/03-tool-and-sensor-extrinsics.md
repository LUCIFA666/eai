# 工具端与传感器外参

## 本章概述

机器人不仅需要描述自身的机械结构，还需要准确描述各种末端工具和传感器与机器人本体之间的空间关系。例如，机械臂抓取任务需要知道夹爪真正接触物体的位置，相机识别出的目标需要知道相对于机器人安装在什么位置，IMU 测得的姿态需要知道对应的是机器人哪个部件，而力/力矩传感器反馈的受力方向也必须明确其参考坐标系。这些空间关系统称为**外参（Extrinsics）**，是机器人系统中连接机械结构、传感器数据和控制算法的重要桥梁。

需要注意的是，机器人系统中的外参主要分为两类。一类是**工具端外参（Tool Extrinsics）**，用于描述机器人执行动作时真正的作用点在哪里；另一类是**传感器外参（Sensor Extrinsics）**，用于描述传感器数据来源于哪个坐标系，以及如何与机器人本体建立空间联系。这两类外参虽然用途不同，但都会作为机器人接口的重要组成部分，被规划控制、视觉感知、数据记录和真机部署等多个模块共同使用。

本章将介绍工具端外参与传感器外参在机器人系统中的作用，说明 Tool Frame、TCP、Camera Frame、IMU Frame、Force/Torque Sensor Frame 等常见坐标系的职责，并介绍 Hand-Eye Transform、Tool Calibration、Sensor Extrinsics 和 Mount Offset 等工程概念。同时，还将讨论外参信息的版本管理以及外参错误对机器人系统带来的影响。本章重点关注外参在机器人接口中的组织方式和数据管理，不涉及相机标定、手眼标定算法或实验流程，这些内容将在第 3 章视觉感知与标定章节中详细介绍。

## 工具端外参与传感器外参的作用

机器人执行任务时，需要同时知道"机器人真正作用于环境的位置"以及"传感器观察环境的位置"。这两个问题分别由工具端外参和传感器外参解决。

### 工具端外参

工具端外参（Tool Extrinsics）用于描述机器人末端工具与机械臂法兰之间的空间关系，即机器人真正执行操作的位置和方向。

例如，机械臂安装夹爪、吸盘、焊枪、螺丝刀等不同工具后，虽然机械臂法兰的位置没有变化，但真正与环境发生交互的位置已经发生改变。工具端外参就是用于描述这种偏移关系，使机器人能够准确计算工具尖端的实际位姿，而不是仅计算法兰盘的位置。

运动规划、抓取控制、轨迹执行等模块通常都以工具端坐标系作为控制目标，因此工具端外参直接影响机器人动作的精度。

### 传感器外参

传感器外参（Sensor Extrinsics）用于描述各种传感器安装在机器人上的位置和姿态。

例如，相机安装在机器人头部、机械臂腕部或底盘前方，不同安装方式都会对应不同的外参；IMU 固定在机器人机身中心，激光雷达安装在机器人顶部，力/力矩传感器安装在腕部，这些设备都需要通过外参与机器人建立统一的空间关系。

传感器采集的数据首先产生于自身坐标系，机器人需要利用传感器外参将这些数据转换到机器人本体坐标系或世界坐标系，才能进一步完成目标定位、运动规划和控制执行。

因此，工具端外参与传感器外参分别解决了机器人"如何作用于环境"和"如何感知环境"两个基础问题，共同构成机器人空间接口的重要组成部分。

## 常见工具端与传感器坐标系

机器人系统中，不同工具和传感器通常采用较为统一的 Frame 命名方式，这些坐标系共同描述机器人末端执行器和各类传感器的安装关系。

### Tool Frame

Tool Frame 表示机器人当前工具的参考坐标系。它通常建立在夹爪中心、吸盘中心、焊枪枪尖或其他实际执行任务的位置，是运动规划和轨迹控制最常使用的目标坐标系。
当机器人更换工具时，Tool Frame 通常也会随之改变。

### TCP（Tool Center Point）

TCP（Tool Center Point）表示机器人末端工具真正与环境发生作用的点。

例如：

- 两指夹爪的夹持中心；
- 吸盘的吸附中心；
- 焊枪的焊接点；
- 螺丝刀的刀尖。

很多工业机器人控制器直接采用 TCP 作为末端控制对象，因此机器人运动控制实际上控制的是 TCP，而不是机械臂法兰。

Tool Frame 与 TCP 在很多系统中可以重合，也可能分别表示工具参考坐标系和工具实际工作点。

### camera_link

camera_link 表示相机本体坐标系。

它通常建立在相机安装位置，用于描述相机整体在机器人中的安装关系。

camera_link 更多服务于机器人装配和坐标树组织，而不是视觉算法本身。

### camera_optical_frame

camera_optical_frame 表示相机光学坐标系。

深度图像、彩色图像、点云以及视觉算法输出的数据通常都采用该坐标系。

camera_optical_frame 与 camera_link 之间通常存在固定的静态变换，用于完成机器人装配坐标与视觉成像坐标之间的转换。

### IMU Frame

IMU Frame 表示惯性测量单元的参考坐标系。

IMU 输出的角速度、加速度和姿态估计结果都属于该坐标系，因此机器人融合 IMU 数据时，需要首先利用外参将其转换到机器人本体坐标系。

### Force/Torque Sensor Frame

Force/Torque Sensor Frame 表示六维力/力矩传感器所在的参考坐标系。

力控机器人通常需要明确：

- 力的方向属于哪个坐标系；
- 力矩绕哪个坐标轴定义。

如果力传感器坐标方向定义错误，即使测量值正确，也可能导致机器人沿错误方向执行力控制。

## 外参接口中的常见概念

机器人系统中的外参不仅包含空间变换，还涉及多个具有明确工程含义的接口概念。

### Hand-Eye Transform

Hand-Eye Transform（手眼变换）描述机器人末端执行器与相机之间的空间关系。

根据相机安装位置不同，可分为：

- Eye-in-Hand（相机安装在机械臂末端）
- Eye-to-Hand（相机固定安装在环境中）

无论采用哪种方式，其本质都是建立机器人运动坐标系与视觉坐标系之间的变换关系，使机器人能够根据视觉结果完成抓取和操作。

### Tool Calibration

Tool Calibration（工具标定）用于确定工具相对于机器人法兰或默认工具坐标系的空间偏移。

例如，更换不同长度的焊枪、安装新的夹爪或更换吸盘后，都需要重新进行工具标定，以保证机器人控制的 TCP 与实际工具尖端保持一致。

工具标定得到的结果通常直接更新 Tool Frame 或 TCP 外参。

### Sensor Extrinsics

Sensor Extrinsics 表示传感器与机器人本体之间的外部几何关系。

对于相机、激光雷达、IMU 等设备，其安装位置和姿态都会作为外参保存，并用于坐标转换、数据融合和空间定位。

Sensor Extrinsics 是机器人多传感器协同工作的基础。

### Mount Offset

Mount Offset 表示设备安装过程中产生的固定偏移量。

例如，相机安装支架、工具连接法兰、传感器安装底座等都会引入一定的位置和姿态偏移。

这些偏移通常属于机器人机械装配的一部分，需要通过配置文件或模型参数进行统一管理，而不是在算法中临时修正。

## 外参的版本管理

机器人系统中的外参并不是永久固定不变的。随着设备维护、工具更换、传感器重新安装或重新标定，外参都会发生变化。因此，外参应当作为一种可追踪的工程资产进行版本化管理，而不能仅保存一组坐标数值。

一个完整的外参记录通常应至少包含以下内容：

- 标定时间（Calibration Time）
- 标定方法（Calibration Method）
- 使用设备（Device）
- 适用机器人型号或编号（Robot Identifier）
- Frame 命名（Frame Name）
- 单位（Unit）
- 外参版本号（Version）

例如，同一台机械臂在更换夹爪或重新安装相机后，应生成新的外参版本，而不是覆盖旧数据。这样不仅能够保证当前系统使用正确的空间关系，也能够确保历史数据集、实验结果和模型训练过程能够依据对应版本进行复现。

对于长期运行的机器人平台，建议将外参与机器人模型、配置文件和数据集版本统一管理，使机器人软件、标定数据和实验记录始终保持一致。

## 外参错误对系统的影响

由于工具端外参和传感器外参贯穿机器人感知、规划和控制全过程，因此外参配置错误通常会导致多个模块同时出现问题。

首先，**抓取点偏移**是最常见的现象。如果工具端外参配置错误，机器人规划的抓取位置将与真实工具作用点存在固定偏差，导致夹爪始终抓偏，即使视觉识别和运动规划完全正确，也无法完成抓取任务。

其次，**深度点云错位**。如果相机外参或 camera_link 与 camera_optical_frame 的关系配置错误，深度点云与机器人模型之间将无法正确对齐，表现为目标物体位置整体偏移、倾斜或方向错误，影响三维感知和目标定位。

第三，**力控方向错误**。当力/力矩传感器坐标系定义错误时，机器人虽然能够正确读取传感器数据，但控制器会将力解释为错误方向，从而导致阻抗控制、柔顺控制或装配任务执行异常，甚至产生危险动作。

此外，**数据集标签无法复现**也是外参错误带来的重要影响。机器人采集的数据通常依赖于对应版本的外参，如果后续重新标定却没有保存历史版本，那么原始数据中的目标位姿、相机观测和机器人状态将无法重新对应到正确的空间关系，导致数据回放、模型训练和实验复现失去一致性。

因此，在机器人开发过程中，外参不仅需要准确，更需要保持长期一致、可追踪和可复现。

## 本章与视觉标定章节的边界

本章主要介绍工具端外参与传感器外参在机器人接口中的组织方式，以及它们如何参与机器人模型、坐标树、控制接口和数据管理。

重点关注的问题包括：

- 工具和传感器如何进入机器人坐标树；
- 各类外参如何组织为统一接口；
- 外参如何影响控制、感知和数据记录；
- 外参如何进行版本管理和工程维护。

而第 3 章将进一步介绍外参的获取过程，包括：

- 相机内参与外参标定；
- 手眼标定算法；
- 工具标定流程；
- 多传感器联合标定；
- 标定实验设计与精度评估。

因此，本章回答的是"外参在机器人系统中如何使用"，而后续章节回答的是"这些外参如何通过标定获得"。

## 本章建议掌握的内容

本章不要求读者掌握具体的标定算法，而是重点理解工具端外参与传感器外参在机器人接口中的作用。

读者应能够区分工具端外参与传感器外参分别解决的问题，理解 Tool Frame、TCP、camera_link、camera_optical_frame、IMU Frame、Force/Torque Sensor Frame 等常见坐标系的职责；能够理解 Hand-Eye Transform、Tool Calibration、Sensor Extrinsics 和 Mount Offset 等工程概念，认识它们在机器人模型、控制系统和感知系统中的位置。

同时，应建立外参版本管理的意识，理解标定时间、标定方法、设备信息、Frame 命名和单位等元数据的重要性，并能够识别外参错误可能导致的抓取偏移、点云错位、力控方向错误以及数据集无法复现等典型问题，为后续机器人感知、规划、控制和数据管理奠定统一的空间接口基础。

## 本章小结

工具端外参与传感器外参是机器人空间接口的重要组成部分，它们分别描述机器人末端工具的实际作用位置以及各类传感器相对于机器人本体的安装关系，为机器人感知、规划、控制和数据记录建立统一的空间参考。Tool Frame、TCP、camera_link、camera_optical_frame、IMU Frame 和 Force/Torque Sensor Frame 等常见坐标系共同构成了机器人末端执行器和传感器的空间表达体系，而 Hand-Eye Transform、Tool Calibration、Sensor Extrinsics 和 Mount Offset 等概念则描述了这些空间关系在工程系统中的来源和作用。

由于外参直接参与机器人目标定位、轨迹规划、力控制以及数据集构建，因此应进行严格的版本化管理，完整记录标定时间、标定方法、适用设备、Frame 命名和单位等信息。工程实践中，外参配置错误不仅会导致抓取点偏移、深度点云错位和力控方向异常，还可能造成历史数据无法回放和实验结果难以复现。因此，应将外参视为机器人接口体系中的基础配置，而不仅仅是标定过程的输出结果，为机器人系统的长期维护、算法开发和真机部署提供一致、可靠的空间基础。
