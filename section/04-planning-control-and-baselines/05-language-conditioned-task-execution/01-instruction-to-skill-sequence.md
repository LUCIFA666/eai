# 指令到技能序列

目标：说明如何把自然语言或视觉语言任务转成机器人可执行的技能序列，并保留可检查的中间表示。

本页需要覆盖：

- 输入：自然语言指令、图像/视频上下文、当前地图、对象列表、机器人可用技能表、任务约束。
- 输出：子任务列表、技能名、目标对象、目标地点、参数槽位、前置条件、终止条件和失败回退策略。
- 技能粒度：`navigate_to`、`pick`、`place`、`open`、`close`、`inspect`、`ask_human` 等应该是可执行接口，而不是一句自然语言描述。
- 任务拆解：单步任务、多阶段任务、条件任务、循环探索任务和需要确认的任务分别如何表示。
- 约束表达：顺序约束、空间约束、安全约束、时间约束、对象状态约束和用户偏好。
- 可审计中间表示：建议用 JSON / YAML 记录 `task_id`、`subgoals`、`skill_calls`、`assumptions`、`uncertainties` 和 `fallbacks`。
- 常见失败：语言歧义、拆解过细、技能不存在、对象未观察到、前置条件不满足、终止条件不可测。

本页只保留写作框架，后续详细写作时应配最小示例：一句指令如何变成 3 到 5 个技能调用。
