# 技能接口与参数绑定

目标：说明技能库不是“自然语言动作列表”，而是带输入输出、前置条件、失败码和安全边界的可执行接口。

本页需要覆盖：

- 技能接口 schema：`name`、`inputs`、`outputs`、`preconditions`、`postconditions`、`timeout`、`safety_limits`、`failure_codes`。
- 常见技能：导航、抓取、放置、开关门/抽屉、推拉、观察、重定位、请求人工确认。
- 参数绑定来源：对象检测结果、6D pose、语义地图、导航 waypoint、抓取候选、用户指令中的约束。
- 参数质量检查：坐标系、时间戳、置信度、可达性、碰撞风险、是否过期、是否需要主动重观察。
- 与下游模块连接：导航技能进入 Nav2，抓取/放置技能进入 MoveIt 2 / cuRobo / RMPflow，策略技能进入第 7 章模型推理接口。
- 与第 2 章动作接口的区别：本页讲技能级调用，第 2 章讲机器人状态、动作空间和控制命令。
- 常见失败：对象 id 绑定错、pose 坐标系错、技能参数不完整、技能声称成功但环境状态未改变。

本页只保留写作框架，后续详细写作时应给出一个技能接口 YAML 和一次参数绑定检查表。
