# 国外研究机构

目标：从国外高校、科研机构、公司研究组和机器人公司入口中判断其研究方向、代表产出和课程可用证据等级。

国外生态既包括长期产出论文和 benchmark 的高校实验室，也包括掌握平台、算力、数据和部署链路的公司研究组。阅读时先按“高校与科研机构团队”和“公司团队”分组，再把机构和具体产出连起来：它做的是机器人学习、具身导航、移动操作、人形、灵巧操作、仿真评测，还是真实系统部署。

## 三、统一证据链

```text
机构主页 -> publication / blog -> 项目页 -> GitHub / model card / SDK -> 数据或 benchmark -> 真实系统证据
```

国外团队常见问题是“论文很完整但硬件和数据不开放”或“demo 很强但技术细节有限”。课程写作时应把论文证据、项目证据、数据证据和平台证据分开记录。

## 四、课程使用边界

| 资料类型 | 可以支持什么 | 不能替代什么 |
|---|---|---|
| 实验室主页和 publication | 长期方向、论文谱系、代表项目 | 不能直接证明项目可复现 |
| 公司 blog / demo / product page | 方向判断、系统形态、平台生态 | 不能替代 benchmark 和失败案例 |
| 项目页和 GitHub | 代码结构、模型包、环境依赖、开放许可 | 不能证明所有论文结果容易复现 |
| 数据集和 benchmark | 任务定义、横向比较、复现实验入口 | 不能替代真实机器人部署能力 |
| SDK 和开发者文档 | 平台接口、仿真链路、部署工具 | 不能消除硬件、权限和安全依赖 |
