# 真机实战

目标:本章带你从 0 搭建一个可复现的真机具身 AI 实验闭环——硬件选型与安全准备、最小真机闭环、硬件检查与标定、真机数据采集、平台适配、训练桥接、真机部署推理,最后到 Sim2Real。

## 本章主线

```text
安全与硬件 → Hello Robot → 硬件检查与标定 → 数据采集（+ 平台适配）
    → 训练桥接（去 7/8 章） → 真机部署推理 → Sim2Real
```

## 三条路径

- **零基础入门**:选型安全 → Hello Robot → 硬件检查与标定 → 采 10 条数据 → 训练 ACT/DP → 低速 rollout。
- **已有机械臂**:硬件检查与标定 → 平台适配页 → 数据采集 → 部署。
- **已有仿真/模型**:真机推理 → Sim2Real。

新手第一次闭环只追求一个目标:用一台单臂完成一个 pick-and-place——能安全上电、读状态、发低速动作、录 10 条成功 demo、replay 检查、训练或微调一个简单策略、低速 rollout 并记录成败。不要一上来就双臂、人形、大 VLA、Sim2Real 全上。

## 本章不重复什么

数据格式与转换原理见第 6 章;策略与 VLA 训练见第 7 章;仿真建模见第 5 章;RL 方法选型见第 9 章;VLA 特有的推理服务与解码加速见第 7 章部署推理。本章只关心:真实机器人如何安全、稳定、可复现地跑起来。

## 完成本章后的产物

- 一份硬件/软件/BOM 记录和一份 bring-up 健康检查报告(`bringup_report.yaml`)。
- 一套相机内参与手眼标定结果。
- 一个可采集、可回放、可质检的真机数据集。
- 一个带 safety filter 的真机推理脚本和 rollout 协议记录。
- 一份失败案例与排障日志。
