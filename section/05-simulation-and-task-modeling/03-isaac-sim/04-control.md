# 控制

机器人资产和物理属性配置完成后，下一步是让机器人按你的目标运动。先建立控制链路的理解视角，再从关节位置 / 速度 / 力矩目标开始，走到 IK / RMPflow 这类末端运动生成，最后学会按层级排查控制问题。相机、传感器和 observation 对齐放到下一部分单独讲。

## 本节目标

本节围绕下面几个问题展开：

1. 动作命令从代码到机器人关节，中间经过哪些层？
2. 位置控制、速度控制、力控制或运动生成分别适合什么情况？
3. 如何判断机器人不动、乱动或抖动的原因？
4. 最小控制实验应该保存哪些现象或数值作为验收？

## 本部分主线

这一部分的顺序是从底层到上层，再回到调试：

```text
控制链路
  → 关节目标控制
  → 末端运动生成
  → 控制排查
```

这样安排的原因是：初学者最容易把“设置状态”“发动作”“调 drive”“做 IK”混在一起。先把边界分清，再写代码，最后才知道问题该往哪一层归因。
