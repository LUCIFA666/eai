# 任务与场景自动生成

本节介绍仿真任务与场景的自动生成工具链：如何用 LLM / 程序化方法批量生成任务定义、场景布局、资产组合和成功判定，从而扩大仿真训练与评测的任务分布。第 8 章评测工程已把 GenSim 类工具划归仿真与数据侧，本节承接该边界。

## 需要覆盖

- 为什么需要任务自动生成：手写任务的覆盖率瓶颈与长尾分布问题。
- GenSim / GenSim2：LLM 生成仿真任务代码与演示的代表工作，https://github.com/liruiw/GenSim 。
- RoboGen：生成式仿真 pipeline（任务提议、场景生成、技能学习），https://robogen-ai.github.io/ 。
- RoboVerse 等统一仿真与任务集合平台的定位，https://roboverseorg.github.io/ 。
- 程序化场景生成（随机布局、物体资产库、域随机化）与第 6 章仿真生成数据集（MimicGen 一族）的分工。
- 自动生成任务的质量验收：可解性检查、成功判定可靠性、任务多样性度量。
