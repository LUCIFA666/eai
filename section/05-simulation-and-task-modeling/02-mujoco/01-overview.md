# 认识 MuJoCo

这一章我们先不深入 API 细节，而是建立一个整体印象：一个 MuJoCo 程序，是怎么从一个模型文件，一步步跑成一段仿真的。先有这么一张全局地图，后面钻进具体函数时才不容易迷路。

这张地图只有一条主线：模型文件（MJCF）描述机器人长什么样，编译后变成内存里的两份数据 mjModel 和 mjData，再由一个 step 循环不断往前推进。后面每一章，无论讲建模、控制还是渲染，都是在这条主线的某个位置补细节；先把这条线立起来，后面读到的东西就有地方安放。

读这一章只要会写基础 Python，对“物理仿真”有个模糊印象就够了；没接触过物理引擎也不要紧，这里从零讲起。读完这三页，我们会对 MuJoCo 有一个整体印象，并在自己的机器上跑出第一个仿真，再往后进入建模、控制这些细节时就有了着落。
