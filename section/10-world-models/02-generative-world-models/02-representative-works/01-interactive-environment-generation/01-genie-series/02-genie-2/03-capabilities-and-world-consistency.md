# 生成能力与世界一致性

## 评价生成式世界模型的关键问题

生成式世界模型不能只看单帧画质。

一个可以训练或评测 agent 的环境还需要满足：

```text
动作能够改变未来
相同场景在不同动作下产生不同轨迹
离开视野的物体不会立即被忘记
重新返回旧区域时场景保持相对一致
物体交互会产生合理状态变化
环境中的角色和 NPC 能持续运动
```

Genie 2 官方展示的能力主要围绕这些问题展开。

## 动作控制

Genie 2 能够识别画面中哪个对象是当前受控角色，并让该角色响应键盘和鼠标操作。

例如：

```text
按 W：
角色或相机向前移动

按 A 或 D：
角色向侧面移动或转向

按 Space：
角色跳跃

移动鼠标：
改变观察方向
```

模型需要避免错误地移动背景中的树木、建筑或云层。

动作控制视频已在“概览与技术演进”页面展示；该示例说明世界未来必须对用户输入敏感。

动作控制展示的是最基础的交互能力：世界未来必须对用户输入敏感。

## 反事实轨迹

Genie 2 可以从同一个初始画面生成不同轨迹。

可以表示为：

```text
相同初始状态
+ 动作序列 A
-> 轨迹 A

相同初始状态
+ 动作序列 B
-> 轨迹 B
```

这种能力称为生成反事实体验。

<video src="assets/genie2-counterfactual-trajectories.mp4" controls width="100%"></video>



反事实轨迹对 agent 训练有潜在价值。

智能体可以在相同起点尝试不同策略，并观察：

```text
向左和向右会发生什么
接近物体和绕开物体有什么区别
攻击和不攻击会产生什么结果
不同导航路线会到达哪些区域
```

这类数据有助于研究决策、规划和策略比较。

## 长期记忆与物体持续性

三维导航中，许多物体会暂时离开相机视野。

例如：

```text
角色转身
-> 房屋离开视野
-> 角色绕行一段距离
-> 再次回头
```

一个没有记忆的生成模型可能重新生成一栋完全不同的房屋。

Genie 2 展示了对离开视野区域的部分记忆能力。模型能够在物体重新进入视野时恢复相对一致的外观和位置。

<video src="assets/genie2-long-horizon-memory.mp4" controls width="100%"></video>

这种能力可以理解为隐式物体持续性：

```text
物体暂时看不见
不代表物体从世界中消失
```

不过，官方展示的是部分案例，并不能说明模型在任意场景、任意时间跨度下都能保持精确地图。

## 动态生成新区域

当用户不断向前移动时，模型需要生成初始图像中从未出现过的新区域。

```text
初始画面只展示一部分世界
-> 用户继续移动
-> 模型生成新的道路、建筑和景观
```

Genie 2 可以在交互过程中即时补充新的视觉内容，并在部分案例中维持最长约一分钟的世界。

<video src="assets/genie2-long-world-generation.mp4" controls width="100%"></video>


生成新内容时，模型需要同时处理两类要求：

```text
新区域要有多样性
旧区域要保持一致性
```

过度追求新颖性可能造成世界漂移；过度复制已有画面则会让环境缺少扩展性。

## 多种观察视角

Genie 2 能够生成多种类似游戏的观察方式：

```text
第一人称视角
第三人称角色视角
等距视角
第三人称驾驶视角
```

不同视角具有不同动态规律。

第一人称移动时：

```text
相机本身在世界中移动
近处物体变化更快
转头会引起大范围画面变化
```

第三人称移动时：

```text
角色位于画面中
相机需要跟随角色
环境相对角色发生位移
```

等距视角和驾驶视角又包含不同的相机与角色关系。

模型能覆盖这些视角，说明其训练数据和世界表示并不局限于一种固定相机模式。

## 三维结构

Genie 2 能够生成道路、建筑、山地、洞穴、森林和室内空间等复杂场景。

这些环境在视觉上体现出：

```text
近大远小
遮挡关系
道路延伸
转向后的新区域
建筑内外关系
相机运动引起的透视变化
```

这些现象让画面看起来具有三维结构。

但需要注意：

```text
视觉上具有三维感
不等于模型显式输出三维网格
```

官方并未说明 Genie 2 会输出可直接读取的深度图、地图、碰撞体或三维几何。

## 物体可供性与交互

可供性（affordance）描述一个物体允许什么动作。

例如：

```text
门可以打开
气球可以被击破
爆炸桶可以被射击
物体可以被接近或绕开
```

Genie 2 展示了多种物体交互。

<video src="assets/genie2-object-interaction.mp4" controls width="100%"></video>


模型需要同时预测：

```text
角色动作
物体状态变化
局部视觉效果
后续环境状态
```

例如开门之后，门的姿态需要改变，门后的区域也需要继续生成。

## 角色动画

Genie 2 可以生成不同类型角色的动作，包括：

```text
人形角色行走和跳跃
机器人移动
飞行角色
动物或幻想生物
车辆驾驶
```

这些角色具有不同身体结构和运动规律。

模型需要根据角色外观推断合理的动画形式，而不是对所有角色应用同一种像素位移。

例如：

```text
人形角色使用双腿跑动
鸟类或龙可能扇动翅膀
车辆应沿地面移动
纸飞机或降落伞具有不同飞行方式
```

这种能力也被用于快速测试不同 avatar 在相似环境中的运动效果。

## NPC 与其他智能体

世界中除了受控角色，还可能包含非玩家角色（NPC）或其他 agent。

Genie 2 能够模拟：

```text
其他角色的移动
角色之间的接近和避让
简单互动
环境中的群体行为
```

这意味着模型不仅预测用户控制对象，还需要预测其他角色如何独立变化。

对 embodied agent 来说，其他 agent 会使环境更加复杂，因为世界不再是静态背景。

## 环境物理效果

官方演示展示了多种视觉物理现象：

```text
水流和水面变化
烟雾扩散
重力和下落
点光源和方向光
反射
泛光
彩色照明
```

<video src="assets/genie2-physics-effects.mp4" controls width="100%"></video>


这些能力说明模型从视频中学习到了常见视觉动态。

但它们首先是视觉预测结果，并不意味着模型内部使用准确的流体模拟、刚体求解或光线追踪。

## 从真实照片开始生成

Genie 2 还可以接收真实世界图片。

官方展示了：

```text
风吹动草地
河水流动
真实自然场景被扩展成可探索环境
```

<video src="assets/genie2-real-image-interaction.mp4" controls width="100%"></video>



真实照片实验说明模型具有一定分布外泛化能力。

不过，模型是根据视频经验对图片进行动态扩展，并不等于它准确恢复了照片对应地点的真实三维结构。

## 能力之间的关系

Genie 2 展示的能力并不是相互独立的。

例如，打开一扇门需要同时具备：

```text
动作响应
角色控制
门的可供性
物体状态变化
遮挡更新
门后新区域生成
长期状态保持
```

返回曾经访问的房屋则需要：

```text
导航
相机运动
长期记忆
建筑外观一致性
空间关系保持
```

因此，生成式三维世界的难点不是单独提高图像质量，而是让多种能力在连续交互中共同稳定工作。
