# 概览与问题设定

## 本页目标

本页独立介绍 Genie 3 的研究定位，重点回答：

```text
为什么世界模型不能只做普通视频生成？
什么样的生成结果才能被称为交互世界？
Genie 3 相较前两代改变了什么？
实时、分辨率和长时一致性为什么要同时考虑？
Genie 3 与游戏引擎和三维重建有何区别？
```

## 从视频预测到世界模拟

普通视频生成模型通常回答：

```text
给定文字或初始画面，
接下来可能出现什么视频？
```

模型一次性决定主要轨迹。用户可以观看视频，却很难在播放过程中持续改变角色方向。

世界模型需要回答：

```text
当前环境是什么状态？
如果智能体执行某个动作，
下一状态会发生什么？
```

Genie 3 的基本闭环为：

```text
当前观察
+ 当前动作
+ 交互历史
-> 下一观察
```

新观察继续进入下一轮预测，使环境可以持续响应操作。

## 普通视频为什么不能直接作为环境

视频可以展示车辆行驶、动物运动或角色探索，但一般没有供智能体使用的实时控制接口。

智能体不能在视频中途决定：

```text
向左转弯
进入另一栋建筑
绕过障碍
停止前进
返回刚才的位置
```

如果模型已经预先确定全部未来，动作就不能真正改变环境。

可交互世界至少需要：

| 能力 | 含义 |
| --- | --- |
| 动作敏感性 | 输入动作能够改变下一画面 |
| 轨迹分叉 | 相同起点和不同动作产生不同未来 |
| 时间连续性 | 角色和环境不会无规则跳变 |
| 闭环响应 | 新生成状态可以继续接收动作 |
| 环境记忆 | 离开视野的内容不会立刻被忘记 |
| 低延迟 | 动作输入后能及时产生新观察 |

## Genie 系列的演进

| 版本 | 主要研究问题 | 代表性能力 |
| --- | --- | --- |
| Genie | 无动作标签视频中如何发现控制因素 | latent action、二维平台式交互 |
| Genie 2 | 单张图像如何扩展成三维交互世界 | 多样三维环境和键鼠控制 |
| Genie 3 | 如何实现实时、高分辨率和更长一致性 | 720p、20–24 FPS、数分钟交互、文本世界事件 |

Genie 3 的重点不只是画面更清晰，而是让高分辨率、实时响应和长时稳定同时成立。

## 主要公开能力

| 项目 | 官方公开描述 |
| --- | --- |
| 世界入口 | 文本描述；Project Genie 中也支持图像 |
| 分辨率 | 720p |
| 实时速度 | 首发约 24 FPS，当前模型页约 20–24 FPS |
| 连续交互 | 数分钟 |
| 视觉记忆 | 部分内容可追溯到约一分钟前 |
| 控制 | 导航动作与研究展示中的文本世界事件 |
| 环境类型 | 真实、自然、动画、幻想和历史场景 |

这些指标需要共同观察。

高分辨率但速度很慢，难以实时控制；生成很快但数秒后环境漂移，也难以支持任务；环境稳定但不响应动作，则仍然只是视频。

## 20–24 FPS 的实际意义

20–24 FPS 表示模型每秒完成约二十多次世界更新。

一次更新需要：

```text
读取当前观察和历史
-> 接收用户动作
-> 生成新的 720p 世界画面
-> 将画面返回给用户或智能体
```

延迟过高时，动作和画面之间会出现明显脱节。

因此，帧率不仅影响观看流畅度，也决定智能体能否形成稳定的感知—行动闭环。

## 720p 的实际意义

720p 能够保留更多：

```text
远处道路
小型障碍
角色轮廓
建筑入口
物体边界
植被和地面结构
```

这些细节会影响目标识别、障碍判断和导航规划。

但分辨率越高，每帧生成成本越大。Genie 3 的难点在于同时维持视觉细节和实时速度。

## 为什么数分钟交互困难

实时世界是自回归生成的：

```text
生成当前帧
-> 当前帧进入历史
-> 根据新动作生成下一帧
-> 不断重复
```

早期小错误会被后续生成继续使用。

例如：

```text
房屋位置轻微偏移
-> 偏移进入历史
-> 转身后结构继续变化
-> 回访时房屋可能与原来不一致
```

因此，数分钟一致性意味着模型需要持续维护空间、对象和动作结果，而不仅是输出更长视频。

## 与传统游戏引擎的区别

| 传统游戏引擎 | Genie 3 |
| --- | --- |
| 显式保存坐标和对象状态 | 状态主要隐含在生成历史中 |
| 地图和资产预先建立 | 新区域可随探索生成 |
| 碰撞和物理由程序定义 | 物理表现主要从数据中学习 |
| 状态和奖励可查询 | 不一定提供明确状态接口 |
| 相同条件易于复现 | 生成过程具有随机性 |
| 长时间运行更稳定 | 仍可能漂移或产生幻觉 |

Genie 3 的优势是按需生成和环境多样性；传统引擎的优势是状态明确和物理可验证。

## 与三维重建的区别

NeRF、Gaussian Splatting 等方法通常恢复一个已经存在的场景，并从不同视角渲染。

Genie 3 则能够：

```text
从文本创建不存在的世界
生成新的区域
模拟天气和角色
根据动作实时改变未来
```

可以概括为：

```text
三维重建：
恢复已有场景

Genie 3：
生成并持续模拟新场景
```

代价是 Genie 3 不一定具有显式几何和精确地图。

## 本页小结

Genie 3 的目标不是一次性生成更长视频，而是在用户或智能体持续行动时，实时模拟世界未来。

720p、20–24 FPS、数分钟一致性和最长约一分钟的视觉记忆共同定义了这一能力。它比普通视频生成更接近环境，但仍不同于拥有显式地图和物理状态的传统模拟器。
