

# 物理、自然与多样世界

## 本页目标

Genie 3 的官方演示覆盖真实自然、极端天气、幻想动画和历史环境。

本页重点分析：

```text
模型能够生成哪些类型的世界？
水、天气、光照和运动如何体现环境动态？
自然生态和动画世界分别有什么困难？
视觉物理和数值物理有什么区别？
环境多样性为什么对智能体有价值？
```

## 建模物理世界属性

官方将物理世界建模列为 Genie 3 的主要能力。

展示内容包括：

```text
火山地形
海浪和水面
强风与暴雨
烟雾和颗粒
雪地和山地
飞行和驾驶
灯光与反射
```

模型需要同时更新主体运动、相机变化、地面结构、动态天气和远近景关系。

## 火山机器人

<video src="./assets/genie3-volcanic-robot.mp4" controls width="100%"></video>

该视频来自 Google DeepMind 的 Genie 3 官方演示，展示第一人称轮式机器人在火山岩地形中移动。应观察轮胎与车体稳定性、熔岩和烟雾动态、崎岖地形的连续性以及相机随移动的变化。该案例不能证明模型准确模拟了轮胎摩擦、悬挂系统或车辆动力学参数。

## 极端天气

官方还展示了暴雨、强风和海浪环境。

这类场景要求模型同时处理：

```text
海浪
雨水
树木摆动
道路透视
移动相机
能见度和光照
```

多个动态因素必须共同变化，而不能只在画面上叠加简单天气特效。

## 自然生态

<video src="./assets/genie3-natural-world.mp4" controls width="100%"></video>

该视频来自 Google DeepMind 的官方自然世界演示，展示森林、水域、动物、植物或其他生态元素随探索持续变化。需要观察植被层次、动物运动、遮挡关系和环境动态。该案例不能证明模型拥有精确生态规律或长期稳定的动物行为模型。

## 水面和非刚体动态

水、烟雾、雨水和植物包含大量非刚体变化。

模型需要生成：

```text
水面纹理变化
运动产生的水花
光照和反射
风吹动植被
烟雾和颗粒扩散
```

这些现象说明模型学习到直观视觉动态，但不意味着内部执行严格流体力学计算。

## 动画与虚构世界

Genie 3 还能生成：

```text
幻想生物
折纸风格动物
发光森林
漂浮岛屿
动画式建筑
不符合现实重力的场景
```

动画环境不仅是纹理风格变化。模型还需要根据角色结构推断：

```text
四足角色如何奔跑
飞行角色如何转向
折纸材质如何保持
幻想环境如何维持自身视觉规则
```

## 历史环境

官方展示了古雅典等历史场景。

这类世界可以用于历史体验和教育原型，但不能被视为严格历史复原。

生成结果可能出现：

```text
时代不匹配的细节
不准确的道路布局
虚构建筑
材料和服饰错误
```

## 视觉物理和数值物理

需要区分：

```text
视觉物理：
画面看起来符合日常直觉

数值物理：
质量、速度、接触、碰撞满足明确方程
```

官方没有提供：

```text
质量
摩擦系数
接触力
流体速度场
刚体状态
碰撞网格
```

因此，本教程使用“物理表现”或“直观物理动态”，不把 Genie 3 写成高精度物理仿真器。

## 多样环境对智能体的价值

环境多样性有助于减少智能体对以下内容的记忆：

```text

固定道路
固定…1170 tokens truncated…常根据真实场景的多视角数据建立稳定表示。

Genie 3 可以从文本创建不存在的动态世界，但其几何和对象状态不具有同样明确的显式保证。

## 当前边界

数分钟一致性不意味着：

```text
可以连续运行数小时
所有对象都永久保存
每次回访完全一致
拥有精确可查询地图
所有动作结果都不会丢失
```

仍可能出现小物体消失、建筑变化、道路漂移和角色外观改变。

## 对长程智能体任务的意义

环境记忆使智能体有机会：

```text
绕过建筑后返回
寻找之前见过的目标
在多个区域之间导航
执行多步探索
保留部分操作结果
```

但智能体自身仍需要任务记忆、规划和位置估计。

## 如何评价环境记忆

可以关注：

| 指标 | 含义 |
| --- | --- |
| 回访一致性 | 返回旧位置后主要对象是否仍存在 |
| 对象持续率 | 离开视野的对象能否重新出现 |
| 状态保持 | 用户造成的变化是否持续 |
| 空间闭环 | 绕行后能否回到合理区域 |
| 角色稳定性 | 长轨迹中角色是否变化 |
| 任务持续性 | 长程目标是否仍可完成 |

## 本页小结

Genie 3 可以在数分钟交互中保持较高环境一致性，并恢复约一分钟前出现的部分视觉内容。

房屋粉刷等案例体现了动作结果记忆，但这种记忆仍是隐式生成能力，不等于显式地图、永久存储或确定性的游戏引擎状态。
