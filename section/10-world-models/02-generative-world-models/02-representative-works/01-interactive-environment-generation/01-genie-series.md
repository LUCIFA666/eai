# Genie 系列

Genie 系列是 Google DeepMind 面向生成式世界模型（Generative World Models）提出的一系列代表性工作。

它关注的核心问题是：

> **模型能否从大规模视觉数据中学习世界如何变化，并进一步生成能够被人类或智能体持续控制的交互环境？**

与普通图像或视频生成不同，Genie 系列并不只希望模型生成一段“看起来真实”的内容，而是进一步要求生成世界能够响应动作。

```
普通视频生成：
输入 Prompt
-> 生成一段视频
-> 后续轨迹主要由模型决定

交互式世界模型：
当前世界
+ 用户或智能体动作
-> 下一世界状态
-> 继续接收动作
-> 持续生成新的未来
```

因此，Genie 系列逐渐将视频生成、世界建模和智能体学习连接到同一个问题中。

## 从视频学习可交互世界

训练一个传统动作条件世界模型，通常需要：

```text
当前状态
+ 真实动作
+ 下一状态
```

例如，在游戏中需要同步记录玩家按下的键，在机器人系统中需要保存机械臂控制命令。

但互联网中的大规模视频通常只有视觉内容：

```text
角色发生了移动
机械臂抓取了物体
车辆改变了方向
```

模型可以看到“发生了什么”，却不知道对应的真实动作是什么。

Genie 系列首先尝试解决这一数据限制。

第一代 Genie 提出从无动作标签视频中自动学习潜在动作（Latent Action），并进一步学习：

```text
当前视觉状态
+ latent action
-> 下一视觉状态
```

这使普通视频也有机会被用于构建动作条件生成环境。

## Genie 系列的技术演进

Genie 系列围绕“如何生成更加通用的交互世界”逐步扩展。

| 模型      | 核心问题                  | 代表性能力                          |
| ------- | --------------------- | ------------------------------ |
| Genie   | 没有动作标签时，如何从视频中发现控制结构  | Latent Action、二维平台式交互环境        |
| Genie 2 | 如何从视觉输入生成更加复杂的三维世界    | 单张图像扩展为可控制的 3D 交互环境            |
| Genie 3 | 如何进一步提高实时性、视觉质量和长期一致性 | 720p、20–24 FPS、数分钟交互、环境记忆与世界事件 |

可以将三代模型的演进概括为：

```text
Genie
从视频中学习“如何控制世界”
        ↓
Genie 2
将交互扩展到更加复杂的 3D 世界
        ↓
Genie 3
让生成世界更加实时、持续和开放
```

### Genie：从视频中发现动作

第一代 Genie 的关键问题是：

```text
视频没有动作标签，
模型如何知道角色为什么发生移动？
```

Genie 将动作视为隐藏变量，并通过潜在动作模型（Latent Action Model，LAM）自动发现视频中的控制结构。

模型进一步使用动作条件动力学模型学习：

```text
过去的视频
+ latent action
-> 下一帧视频
```

最终，用户可以直接选择 latent action，使同一个初始图像产生不同未来。

第一代 Genie 主要在二维平台游戏视频中验证这一思想，同时还探索了机器人视频和无动作专家视频中的策略学习。

### Genie 2：从图像扩展到三维交互世界

Genie 2 将问题进一步扩展到更加复杂的三维环境。

其核心目标不再只是学习二维角色的有限动作，而是：

```text
给定一个视觉世界起点，
能否生成可以持续移动和探索的 3D 环境？
```

用户或智能体可以通过键盘和鼠标控制角色，在生成环境中移动。

模型需要持续处理：

```text
相机变化
空间透视
遮挡关系
角色动画
新区域生成
环境动态
```

这使 Genie 系列开始从“可控制视频”进一步接近“生成式三维环境”。

[进入 Genie 2 专题](01-genie-series/02-genie-2.md)

### Genie 3：实时生成持续世界

Genie 3 将研究重点进一步推进到实时世界模拟。

Google DeepMind 公开展示的 Genie 3 能够：

```text
根据文本描述生成世界
以 720p 输出环境
以约 20–24 FPS 实时运行
持续交互数分钟
保留部分约一分钟前的视觉内容
生成物理、自然、动画和历史环境
通过文本触发 Promptable World Events
支持智能体进入生成世界执行任务
```

在 Genie 3 中，世界并不是一次性生成完成。

用户或智能体持续输入动作：

```text
当前观察
+ 当前动作
+ 交互历史
-> 下一观察
```

当用户转向此前没有观察的区域时，模型需要实时生成新的道路、建筑、地形和对象。

这使 Genie 系列进一步从视频生成走向持续世界模拟。

## 三代 Genie 解决了什么问题

从世界模型角度看，三代 Genie 分别推进了三个关键问题。

### 动作从哪里来

第一代 Genie 研究：

```text
无动作标签视频
-> 自动发现 latent action
```

它降低了动作条件世界模型对真实控制日志的依赖。

### 世界可以有多复杂

Genie 2 将生成范围从二维平台环境扩展到更加丰富的三维世界。

核心问题变成：

```text
动作发生后，
空间、相机和环境应该如何共同变化？
```

### 世界能够持续多久

Genie 3 开始重点处理实时性和长期一致性。

生成环境需要记住：

```text
之前出现过哪些对象
用户从哪里经过
环境发生过什么变化
离开视野的区域是什么样
```

因此，Genie 系列的研究问题逐渐从：

```text
能不能控制生成视频
```

发展为：

```text
能不能生成一个持续存在并响应智能体动作的世界
```

## 为什么 Genie 对具身智能重要

具身智能体需要通过与环境交互学习。

传统训练环境主要来自：

```text
真实机器人
人工构建模拟器
商业游戏
固定 benchmark
```

这些环境通常面临：

```text
真实数据采集成本高
模拟场景需要人工制作
环境数量有限
视觉和任务多样性不足
```

生成式世界模型提出了另一种可能：

```text
文本、图像或视频
-> 世界模型
-> 大量新的交互环境
-> 智能体在其中探索和学习
```

如果世界模型能够保持可靠的动作响应、物理规律和长期状态，智能体就可能获得规模更大的训练环境。

例如，可以自动构造：

```text
不同天气
不同地形
不同视觉风格
未见地图
动态障碍
反事实场景
失败恢复任务
```

因此，Genie 系列的重要意义并不只是“生成游戏”。

它更重要的研究价值在于：

> **尝试使用生成模型直接构建智能体能够感知、行动和学习的世界。**

## 生成式世界模型仍然面临的问题

Genie 系列虽然不断提升交互能力，但生成世界与成熟模拟器之间仍有明显差距。

关键问题包括：

| 问题     | 核心挑战             |
| ------ | ---------------- |
| 动作一致性  | 相同动作是否稳定产生相似结果   |
| 长期记忆   | 离开视野的对象和区域能否被保留  |
| 空间一致性  | 回到旧区域时世界是否仍然相同   |
| 物理可靠性  | 视觉合理是否对应正确动力学    |
| 实时生成   | 高分辨率环境能否低延迟更新    |
| 任务可完成性 | 目标和道路是否持续存在      |
| 多智能体交互 | 多个角色的状态和行为如何共同保持 |
| 实验复现   | 随机生成环境如何进行公平评测   |

尤其对于机器人和具身智能研究，需要区分：

```text
画面看起来合理
```

和：

```text
环境动力学真正可靠
```

一个视觉上非常逼真的世界，如果动作响应错误、目标随机消失或道路不断变化，仍然无法直接作为高质量机器人模拟环境。

## 本节小结

Genie 系列展示了生成式世界模型的一条清晰演进路线：

```text
从无动作视频学习控制
-> 生成可操作的视觉轨迹
-> 扩展到复杂三维环境
-> 提高实时生成能力
-> 延长环境记忆和一致性
-> 支持具身智能体进入生成世界
```

第一代 Genie 解决“动作从哪里来”，Genie 2 探索“如何生成复杂三维世界”，Genie 3 则进一步研究“如何让世界实时、持续并支持智能体行动”。

从这一视角看，Genie 系列的目标已经不只是视频生成，而是逐步逼近一种新的环境生成范式：

> **按需生成可以被人类和智能体持续探索、控制和学习的世界。**
