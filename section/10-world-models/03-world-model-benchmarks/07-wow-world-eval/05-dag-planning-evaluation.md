# DAG 长程规划评测

长程机器人操作通常包含多个子目标，部分步骤具有严格前置条件，另一些步骤可以交换顺序。WoW-World-Eval 将任务表示为有向无环图（Directed Acyclic Graph，DAG），使规划评测从单一线性序列比较转为动作节点与依赖关系比较。

## 原子动作与依赖边

任务图记为

\[
G=(N,E).
\]

节点 \(n\in N\) 是带参数的原子动作：

\[
n=\langle \mathrm{skill},\mathrm{object},\mathrm{args}\rangle.
\]

`skill` 表示抓取、抬起、放置或打开等动作，`object` 表示作用对象，`args` 保存目标位置或另一个关联对象。边 \((n_i,n_j)\in E\) 表示 \(n_j\) 只能在 \(n_i\) 之后发生。

例如，将物体放入抽屉至少要求抽屉处于打开状态，并要求物体已经被抓取。打开抽屉和接近物体可能不存在直接依赖，因而两者可以有多种合法排列。DAG 保存必要的偏序约束，不把人工参考视频中的唯一时间排列当作全部正确答案。

## 参考图与预测图

参考指令和 GT 视频共同构成参考计划，生成视频经过相同的动作解析过程得到预测计划。评测数据流可以写为

\[
(p,V)\longrightarrow G^\star,
\qquad
\hat V\longrightarrow \hat G.
\]

\(G^\star\) 是参考 DAG，\(\hat G\) 是生成视频对应的预测 DAG。两者之间的差异可能来自生成模型，也可能来自视频动作解析器。动作词表、视频解析提示词、节点合并规则和边生成算法目前尚未公开，因此无法独立重建 DAG。

## Node Correctness

Node Correctness 计算预测图中正确原子动作的覆盖程度。节点匹配同时涉及 skill、object 和 args，而不是只判断视频中是否存在运动。以下错误会降低节点正确性：

- 遗漏必要子目标；
- 对错误对象执行正确动作；
- 动作类型错误；
- 目标位置或参数错误；
- 生成与任务无关的动作。

有效正文将该项描述为正确预测节点所占比例，未给出最终实现使用的精确匹配、近义动作归并或重复节点处理规则。该分数主要表示计划包含了多少正确组成，不单独验证这些动作能否按照依赖关系完成任务。

## Task Completion

Task Completion 使用多模态大模型进行轻量世界模拟。模拟器接收三类参考信息和一个预测计划：

| 输入 | 提供的信息 |
| --- | --- |
| 首帧图像 | 初始对象、空间关系和物理约束 |
| 参考动作列表 | 完成任务所需的动作集合 |
| 参考 DAG | 动作前置关系和允许的顺序 |
| 预测 DAG | 生成视频实际呈现的计划 |

模拟过程从首帧恢复初始世界状态，再依据参考动作和依赖图识别任务阶段。预测动作逐步作用于该状态；只有满足前置条件并产生相应对象状态变化的步骤，才计入已完成阶段。节点名称正确但顺序不可执行的计划仍会受到惩罚。

Task Completion 仍是 MLLM 代理模拟。它不运行动力学仿真，不接收真实机器人反馈，状态谓词、阶段划分和 rollout 提示词目前尚未公开。分数表示预测 DAG 在论文所用轻量模拟器中的阶段覆盖，不等于物理任务成功率。

## LongHorizon

最终规划分数以相同权重结合 Node Correctness 与 Task Completion：

\[
S_{\mathrm{LongHorizon}}
=50\left(
S_{\mathrm{NodeCorrectness}}
+S_{\mathrm{TaskCompletion}}
\right).
\]

当两个组成项采用 0–1 范围时，`LongHorizon` 落在 0–100。Node Correctness 保留计划组成，Task Completion 保留依赖和阶段推进；两项共同避免只按动作词命中率或只按最终状态计分。

| 失败形式 | Node Correctness | Task Completion |
| --- | --- | --- |
| 遗漏必要动作 | 降低 | 后续阶段可能无法到达 |
| 动作存在但对象错误 | 降低 | 状态更新错误 |
| 动作节点正确但顺序违反依赖 | 可能保持 | 降低 |
| 多个无依赖动作采用不同合法顺序 | 应保持 | 应保持 |
| 视频静止或没有任务相关动作 | 接近最低 | 接近最低 |

## 分数解释

规划分数只作用于 25 条长程规划样本。主结果中最高 Planning DAG 分数仍为 17.27，表明当前模型很少同时覆盖正确子目标和可推进的依赖结构。该低值也受到解析器与 MLLM rollout 的影响，不能全部归因于视频模型内部没有规划表示。

DAG 标注、动作解析器、MLLM 版本与配置、提示词、中间节点匹配结果和 Task Completion 状态轨迹目前均未公开。在这些工件尚未公开的情况下，规划分数无法独立复算，替换解析器后得到的数值也缺少直接比较基础。
