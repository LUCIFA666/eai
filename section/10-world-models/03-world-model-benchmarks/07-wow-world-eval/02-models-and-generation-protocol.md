# 参评模型与生成协议

WoW-World-Eval 在统一的初始图像与语言指令条件下比较商业视频生成模型、开源视频生成模型和具身世界模型。统一任务接口消除了 Text-to-Video 与 Image-to-Video 的输入差异，但模型版本、训练域、参数规模、输出分辨率和 backbone 仍然不同。这些条件共同决定结果表所比较的模型实例。

## 模型设置

| 模型 | 类别与版本 | 论文报告的生成设置 |
| --- | --- | --- |
| Kling | 商业闭源视频模型，Kling v2.1 | 5 秒，720p |
| Hailuo | 商业闭源 Image-to-Video 模型，Hailuo I2V-02 | 5 秒，768p |
| CogVideoX | 开源通用视频模型，CogVideoX-I2V-5B | 5B，5 秒，1360×768 |
| Cosmos-Predict1 | 开源世界模型 | 7B，5 秒，720p |
| Cosmos-Predict2 | 开源世界模型 | 2B，5 秒，720p |
| Wan2.1 | 开源通用视频模型，Wan2.1-I2V-14B | 14B，5 秒，832×480 |
| WoW-cosmos1 | 具身世界模型，7B Cosmos-Predict1 backbone | 沿用对应 backbone 的视频设置 |
| WoW-cosmos2 | 具身世界模型，2B Cosmos-Predict2 backbone | 沿用对应 backbone 的视频设置 |
| WoW-wan | 具身世界模型，14B Wan backbone | 沿用对应 backbone 的视频设置 |

Kling 和 Hailuo 代表可公开访问但内部实现目前不可见的商业系统。CogVideoX 与 Wan 主要从通用图像—视频语料学习生成能力。Cosmos-Predict 面向视频状态预测和世界生成。WoW 在不同 backbone 上加入机器人操作数据和具身预测目标，因而 WoW 与对应 backbone 的对照可以观察训练域变化，而不是只比较网络规模。

论文未报告商业模型的参数量，也未给出所有模型统一的采样器、步数、随机种子、压缩率或帧率。表中的 720p、768p 和具体像素分辨率也不是同一书写口径。结果因此对应论文实际使用的模型服务和本地版本，不能解释为完全受控的架构消融。

## 生成输入与输出

所有模型接收同一类条件：

\[
(I_0,p)\longrightarrow \hat V.
\]

\(I_0\) 固定视频首帧，模型不能通过重新生成起始场景改变机器人或物体布局；\(p\) 是主要的可控输入。不同模型生成的视频时长均报告为 5 秒，但输出空间分辨率不同。参考指标需要在生成视频与 GT 视频之间完成帧、尺寸或特征层面的对齐，分辨率差异仍会影响像素细节、掩码边界和轨迹估计。

模型的训练域也改变同一协议的难度。通用视频模型可能把机器人动作替换为更常见的人类动作，具身模型则更可能保持机械臂外观与操作模式。商业模型的训练数据目前不可见，因此高视觉质量不能直接归因于某一数据来源或训练方法。

## 简短提示词

主结果使用只描述任务目标的简短提示词。该设置要求模型自行从首帧识别环境和对象，并将目标指令分解为动作过程。提示词不补充场景细节、逐步执行计划或物理约束，因此评测同时受到视觉条件理解和语言条件完整性的影响。

简短提示词具有两个作用。其一，同一任务不会因人工编写的大量步骤而预先包含规划答案；其二，欠充分的文字条件可能使模型无法确定对象属性、子目标或接触方式。主结果测量的是模型在这种任务级指令下的表现，而不是所有可用提示工程下的能力上限。

## 密集提示词

密集提示词实验使用 InternVL3-78B 扩展原始短指令，补充环境与对象描述、子目标和物理约束。首帧保持不变，变化只发生在语言条件。该实验由此比较

\[
g(I_0,p_{\text{short}})
\quad\text{与}\quad
g(I_0,p_{\text{dense}}).
\]

密集提示词不是新的训练设置，也没有改变模型权重。它检验文字条件是否能够补偿场景语义和执行细节不足。论文结果显示，多数模型的视觉质量、指令理解和物理规律分数上升，而规划分数变化较小。该差异说明丰富文字能够提供更多可见目标与物理线索，但不能替代模型内部的长程任务分解。

## 比较范围

| 差异来源 | 对结果的直接影响 |
| --- | --- |
| 模型版本与访问时间 | 商业服务可能对应不可恢复的固定版本 |
| 参数规模和 backbone | 表征容量与生成先验不同 |
| 通用视频或机器人训练域 | 机械臂身份、接触动作和真实轨迹的先验不同 |
| 输出分辨率 | 像素指标、局部纹理、掩码与轨迹精度不同 |
| 简短或密集提示词 | 条件中显式给出的对象、步骤和物理约束不同 |

排行榜适合比较论文所用实例在固定数据和提示词协议下的结果。缺失的生成参数阻止了严格复算，也限制了对模型架构、数据规模或参数量的单因素归因。
