# Controllability

Controllability 将条件响应拆成三种证据：Instruction Following 直接判断单段视频是否完成指令，Semantic Alignment 比较生成视频与 GT 视频的描述，Action Following 检查同一起点下不同指令是否产生可区分结果。

| 指标 | 参照 | 高分表示什么 |
| --- | --- | --- |
| Instruction Following | 指令与抽样帧 | 动作、目标对象和终态符合文字条件 |
| Semantic Alignment | 配对 GT 视频 | 生成视频与 GT 视频描述的 CLIP 文本特征接近 |
| Action Following | 同一回合的多路生成 | 不同指令产生较大的视频特征差异 |

## Instruction Following

Instruction Following 直接比较指令与生成视频，使用 Qwen3-VL-8B-Instruct 判断文字条件是否在画面中实现。评测器默认从整段视频均匀抽取 16 帧，将按时间排列的帧序列与指令输入固定提示词。判别器分别检查动作类型、目标物体、执行机械臂、空间关系和最终任务状态。例如，右臂把红色方块放到蓝色垫子上同时约束了手臂、物体、动作和终点，满足其中一部分不能视为完整完成。

1 分表示动作、对象或场景完全不符，2 分表示只有部分相关且存在主要错误，3 分表示总体意图正确但执行有误，4 分表示基本完成且只有轻微偏差，5 分表示全部指定要素完成。评测器将分数除以 5，得到 `0.2` 到 `1.0` 的缩放结果。完整 JSON 解析失败时记录 `parse_failed` 并留下空指标；单项缺失或非数值时归一化值为 `0.0`。

以右臂拿起鞋子，将鞋带朝下放进小盒子为例，机械臂必须选择鞋子而不是旁边的物体，使用指定手臂完成搬运，并在终态满足盒子位置和鞋带朝向。只把鞋子移到盒子旁，或者把鞋子放入盒中但鞋带朝上，都只完成了部分条件。关键抓取或翻转若发生在抽样帧之间，判别器可能只看到正确初态和终态，无法确认过程是否符合要求；左右臂在画面中严重遮挡时，也可能被识别错误。该指标依赖可见证据和 VLM 判断，不是程序化任务成功信号。

## Semantic Alignment

Semantic Alignment 同时读取严格配对的生成视频与 GT 视频，但不直接比较像素。Qwen2.5-VL 先分别观看两段视频，为各自生成结构化描述；评测器读取描述 JSON 中的 `General` 字段，再用 CLIP 文本编码器把两段描述转换为文本特征。该过程将右臂抓起红色方块并放到蓝垫上这类视频内容压缩为高层事件与对象语义，因此允许画面纹理、执行速度和具体轨迹不同。

论文定义为

$$
S_{\mathrm{sem}}^{\mathrm{paper}}
=w\max\left(
\frac{f_g^\top f_r}{\lVert f_g\rVert_2\lVert f_r\rVert_2},0
\right),
$$

其中 $f_g$、$f_r$ 是两段描述的 CLIP 特征，$w$ 是论文用于归一化的缩放因子；论文没有在公式附近给出其具体数值。

评测器使用描述 JSON 中的 `General` 字段，直接计算归一化文本特征点积：

$$
S_{\mathrm{sem}}^{\mathrm{eval}}
=\frac{f_g^\top f_r}{\lVert f_g\rVert_2\lVert f_r\rVert_2}.
$$

当前实现没有乘以 $w$，也没有把负值截断为 0。余弦值越高，两段描述在 CLIP 文本空间中越接近；较低或负值表示描述语义相距较远。

假设参考视频描述为右侧机械臂夹住红色杯子，并将杯子从桌面上拿起；生成视频描述为右侧机械臂拿起了桌子上的红色杯子。两句话的措辞和详细程度不同，但机械臂位置、动作和目标物体一致，因此文本特征通常较接近，Semantic Alignment 会较高。如果生成视频描述为右侧机械臂推动了桌子上的蓝色瓶子，那么动作和目标物体都发生了变化，分数会较低。这个指标关注视频总体在做什么，不要求描述文字、执行速度和逐帧轨迹完全一致。

该分数依赖自动生成的视频描述。视频描述模型如果遗漏动作结果、目标物体状态或左右位置，后续相似度便无法反映这些细节；如果描述错误，错误信息也会直接进入 CLIP 比较。例如，生成视频中的右侧机械臂只碰到了桌子上的红色杯子，并没有将其拿起，但视频描述模型将其描述为右侧机械臂拿起了桌子上的红色杯子，这属于动作结果描述错误，可能使 Semantic Alignment 得到偏高的分数。如果模型只写机械臂与红色杯子发生了交互，则遗漏了杯子是否被拿起这一结果。高分表示两段自动描述的总体语义接近，不表示视频动作一定正确，也不表示任务细节都被完整保留。

## Action Following

Action Following 比较同一个回合的多路生成结果，不读取 GT 作为相似性参照。评测协议从同一初始帧出发，分别输入三条不同指令，得到三段视频。评测器用 CLIP 提取每一帧的视觉特征，再沿时间求平均，形成视频级特征 $f_i$。随后两两比较这些视频：内容越相似，余弦相似度越接近 1，`1-cosine` 越接近 0；不同指令产生的整体视觉过程越不相同，平均差异越大。

当 $N\ge2$ 时，评测器实现为

$$
S_{\mathrm{act}}^{\mathrm{eval}}
=\frac{2}{N(N-1)}\sum_{i<j}
\left(1-
\frac{f_i^\top f_j}{\lVert f_i\rVert_2\lVert f_j\rVert_2}
\right).
$$

$N$ 是实际读取的分组数。官方协议取 $N=3$，代码没有强制三组；只有一个分组时没有可比较的视频对，返回 0。实现也没有把 $1-\cos$ 缩放到 `[0,1]`，其理论范围是 `[0,2]`。该分数对应当前回合的多路输出差异，不是单段视频的正确性分数。

以同一张红色杯子和盒子的初始帧为例，三条指令分别要求拿起杯子、把杯子推向桌面左侧，以及把杯子放入盒子。模型若生成三种不同的动作和终态，三段视频的 CLIP 特征差异较大，Action Following 会较高。如果模型忽略指令，三段视频都只生成拿起杯子的动作，视频特征相近，分数会较低。

Action Following 只检查不同指令是否改变输出，不判断变化是否正确。例如，三段视频中的杯子都没有移动，但画面颜色或镜头角度各不相同，CLIP 特征仍可能产生较大差异，使分数偏高。如果三个正确动作只在最后少数帧出现不同终态，逐帧特征经过时间平均后，动作差异也可能被稀释。变化是否符合指令仍由 Instruction Following 补充判断。

## 产生变化与产生正确变化

Action Following 只检查条件是否改变输出，Instruction Following 检查每段输出是否符合文字条件，Semantic Alignment 检查是否接近参考事件。三项联合后才能区分条件忽略、错误多样性和正确响应。
