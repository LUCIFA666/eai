# Habitat Challenge

## 官方资源

| 资源 | 作用 |
| --- | --- |
| [Habitat Challenge](https://aihabitat.org/challenge/) | Habitat Challenge 总入口，包含不同年份的 navigation 和 rearrangement challenge |
| [Habitat Navigation Challenge 2023](https://aihabitat.org/challenge/2023/) | ObjectNav 和 ImageNav 任务说明 |
| [Habitat Rearrangement Challenge 2022](https://aihabitat.org/challenge/rearrange_2022/) | Object Rearrangement 任务说明 |
| [Habitat-Lab](https://github.com/facebookresearch/habitat-lab) | 任务定义、训练、评测和 benchmark 代码入口 |
| [Habitat-Sim](https://github.com/facebookresearch/habitat-sim) | 高性能 3D 仿真器，用于渲染场景和运行 agent |
| [Habitat-Lab Quickstart](https://aihabitat.org/docs/habitat-lab/quickstart.html) | 官方入门示例，可用于理解 PointNav 环境创建和交互流程 |
