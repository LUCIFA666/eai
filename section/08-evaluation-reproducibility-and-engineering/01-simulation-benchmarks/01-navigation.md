# 导航

目标：归类导航与移动智能类仿真 benchmark，后续详细页需要写清任务设置、环境版本、导航指标和失败证据。

## 需要覆盖的 benchmark

| Benchmark | 入口 | 后续详细页需要写清楚 |
|---|---|---|
| OmniNavBench | http://omninavbench.cloud-ip.cc | 覆盖的导航任务、跨构型评测、人类专家轨迹、指标和提交方式 |
| Habitat Challenge | https://aihabitat.org/challenge/ | ObjectNav、ImageNav、Rearrangement 等任务、SPL / Success / SoftSPL、Habitat-Sim / Habitat-Lab 版本 |
| AI2-THOR / RoboTHOR | https://ai2thor.allenai.org/ | 室内交互环境、ObjectNav / PointNav / ManipulaTHOR / RoboTHOR sim-to-real 设置 |
| ALFRED / DialFRED | https://askforalfred.com/ | 语言指令到长程家庭任务、低层动作序列、任务成功率、路径和交互失败类型 |
| TEACh | https://github.com/alexa/teach | 对话式具身任务、Commander / Follower 交互、EDH / TfD 设置、任务成功率 |
