# 结果与发现

下面的结果来自 RoboMemArena 论文，指标为 TSR（全阶段成功率）与 CSR（阶段完成度），均为百分比。

## 主结果

| 方法 | TSR | CSR |
|---|---|---|
| GroundTruth（上界） | 46.1 | 64.8 |
| PrediMem | 38.5 | 55.2 |
| MemER | 27.3 | 49.1 |
| π0.5 | 21.5 | 38.7 |
| HiF-VLA | 16.9 | 39.8 |
| MemoryVLA | 15.0 | 35.3 |
| GPT-5.4 | 8.7 | 30.5 |
| Qwen3-VL-8B（冻结） | 6.0 | 26.2 |

PrediMem 以 38.5 的 TSR 领先所有对比方法，比最强的先前方法 MemER（27.3）高出一截，也明显高于无记忆的 π0.5（21.5）。但它离用真值子任务的上界 GroundTruth（46.1）仍有距离，benchmark 远未饱和。纯 VLM（冻结 Qwen3-VL-8B、GPT-5.4）直接当策略时很弱，说明只有强视觉语言先验、没有面向动作的记忆与执行是不够的。

## 分类别表现

PrediMem 在四类记忆任务上的 TSR 差异很大：

| 类别 | TSR |
|---|---|
| Sequence | 72.5 |
| Counting | 45.7 |
| Occlusion | 27.3 |
| Transferring | 22.5 |

顺序类最好，计数类次之，而遮挡类和搬运类最难——这两类要在长时程里稳定记住不可见容器的内容与源到目标的映射，恰是当前记忆方法最吃力的地方。

## 消融

| 变体 | TSR | CSR |
|---|---|---|
| PrediMem（完整） | 38.5 | 55.2 |
| 去掉预测编码头 | 32.3 | 49.0 |
| 去掉关键帧库 | 17.7 | 41.6 |

去掉预测编码头掉约 6 个点，说明预测下一帧特征的辅助目标确有帮助；去掉关键帧库（只留近期帧）掉到 17.7，接近无记忆水平，说明关键帧记忆是长时程成功的主要来源。骨干换成更小的 Qwen3-VL 也稳定下降：1.7B 得 19.9、4B 得 31.9，8B 最好。预测编码的损失权重取 0.1 时最优。

## 真机迁移

另配一组真机任务验证迁移，PrediMem 平均分最高，且是唯一能完成 IHMB（in-hand memory 类）任务的方法：

| 方法 | 平均分 |
|---|---|
| PrediMem | 52 |
| MemER | 40 |
| π0.5 | 20 |

PrediMem 在各真机任务上的表现为 Pour×2 60、Brush 60、Transfer 80、Shell 50、IHMB 10，其中只有它在 IHMB 上拿到非零分。仿真里遮挡/搬运难、这里 IHMB 难，趋势一致。

## 失败证据

结果之外，还有具体的失败模式，说明缺记忆错在哪：无记忆的 π0.5 会反复重开同一个抽屉——因为它记不住这个抽屉刚才已经检查过；把纯 VLM（GPT-5.4）直接当策略，则在真机迁移上表现很差，无法把强语言先验转成稳定的动作。这些都指向同一点：长时程操作的瓶颈是在动作层面维护并利用记忆，而不是单纯的感知或语言能力。
