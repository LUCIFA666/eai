# 概览与定位

RoboMemArena 是一个面向机器人记忆的大规模长时程 benchmark，26 个操作任务建立在 LIBERO 之上，用一台机械臂在部分可观测环境里完成。它针对的是反应式策略最容易栽的情形：决定下一步动作所需的信息此刻已经不在画面里，物体被藏进抽屉、被换了容器，或某个动作要按次数重复，策略必须依赖历史。

## 要填的缺口

RoboMemArena 从三个方面补已有记忆 benchmark 的不足：

- 多模态记忆标注：记忆本身是多模态的，既有语言子任务、也有视觉关键帧，而已有 benchmark 大多只有稀疏的成功信号。RoboMemArena 给每条轨迹配了子任务指令与原生关键帧标注。
- 覆盖面与结构复杂度：不少 benchmark 偏短期记忆、结构单一，甚至含不真正需要记忆的任务。RoboMemArena 用四类记忆需求、26 个长时程任务扩大覆盖。
- 只有仿真：多数记忆评测停在仿真。RoboMemArena 额外配一组真机任务做物理验证。

## 与其他记忆 benchmark 的区别

在同类记忆 benchmark 里，RoboMemArena 的轨迹最长、历史依赖子任务比例最高。

| Benchmark | 平均轨迹步数 | 历史依赖子任务比例 |
|---|---|---|
| MIKASA-Robo | 约 93 | 58.7% |
| MemoryBench | 约 312 | 38.4% |
| RoboMME | 约 482 | 60.5% |
| RMBench | 约 695 | 42.4% |
| RoboMemArena | 约 1076 | 68.9% |

它也是这几个里唯一同时具备多模态标注（子任务 + 关键帧）与配对真机评测的。配套方法 PrediMem 用双系统加预测编码，作为记忆方法的参考基线。
