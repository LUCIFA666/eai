# 记忆类型与套件

RoboMME 的分类依据认知科学的记忆理论：长期记忆分成过程记忆与陈述性记忆，陈述性记忆再分情节与语义。RoboMME 从中提炼出四个与操作相关的维度，分别回答 when、where、what、how 四个问题，每个维度由一个任务套件承载。这样拆分的用处是：不同记忆机制不再笼统地比"有没有记忆"，而是能在四类明确的需求下分别比较强弱。

## 四维记忆与四套件

| 维度 | 套件 | 记住什么 | 为什么当前观测不够 |
|---|---|---|---|
| 时间记忆（temporal，when） | Counting | 事件的累计次数、顺序、进入下一子任务的时机 | 重复动作之间场景几乎一样，次数只能靠跨步累计 |
| 空间记忆（spatial，where） | Permanence | 物体被遮挡、移动后的位置与空间关系 | 目标被容器盖住或洗牌后离开视野，当前帧看不到 |
| 对象记忆（object，what） | Reference | 跨时间的指代一致性，同一物体的身份 | 正确目标由此前的视觉、语言或动作线索定义，当前帧不含 |
| 过程记忆（procedural，how） | Imitation | 此前演示过的运动模式或操作方式 | 当前状态不编码该怎么接着做，动作方式要从演示回忆 |

四个套件各四个任务，共 16 个。有些任务同时压两类记忆：VideoRepick、VideoPlaceButton、VideoPlaceOrder 兼有对象与时间记忆（既要认出同一物体、又要记住视频里的时序），InsertPeg 兼有过程与对象记忆（既要复现插入方式、又要认准同一根钉子的同一端）。

## Counting：数清重复（时间记忆）

Counting 套件考察时间记忆：把一个动作按要求重复固定次数，或在计到第 N 次时触发。难点在于每次重复后场景几乎回到原样，次数无法从任何一帧读出，只能跨步累计——这正是反应式策略最容易栽的地方。四个任务从不同角度压计数：PickXTimes 数拾放次数，BinFill 数放进料箱的数量与颜色，SwingXTimes 数来回摆动的次数，StopCube 更进一步，要求在方块第 N 次经过目标的那一刻精确触发，把计数和时机敏感叠在一起。

## Permanence：遮挡下的物体永久性（空间记忆）

Permanence 套件考察空间记忆：物体先可见，随后被容器盖住、甚至被洗牌换位，策略要记住它此刻在哪。这里当前帧不可靠，因为目标已经离开视野或位置已变。VideoUnmask 与 ButtonUnmask 考察静态遮挡下的位置记忆，区别只在开头是给演示视频还是用按钮触发；VideoUnmaskSwap 与 ButtonUnmaskSwap 在遮挡之外加入容器交换，把静态的"记住位置"升级成动态的"一路跟住"，因此这两个任务同时带追踪。

## Reference：指回之前的对象（对象记忆）

Reference 套件考察对象记忆：正确目标由此前出现过的线索定义，而不是当前可见的匹配。线索有三种形态，套件覆盖了全部：视觉指代（PickHighlight 记住哪些方块曾被高亮）、动作指代（VideoRepick 记住演示里被操作过的是哪个方块）、语言指代（VideoPlaceButton 用"按钮前/后"、VideoPlaceOrder 用序数来指目标）。因为线索来自开头的演示视频，后三个任务还要维持跨时序的对应关系，兼有时间记忆。

## Imitation：复现演示的方式（过程记忆）

Imitation 套件考察过程记忆：先看一段演示，再用相同的方式复现，考的是"怎么做"而非"做什么"。当前状态并不编码接下来该怎么走，动作方式只能从演示回忆。四个任务覆盖不同的运动模式：MoveCube 复现接触方式（推、拉、抓放），InsertPeg 复现抓取端与插入侧，PatternLock 复现网格上的直线路径，RouteStick 复现绕障碍的环绕方向。这类任务在记忆之外还叠加了精细的动作控制，往往是各方法最难拿分的一组。
