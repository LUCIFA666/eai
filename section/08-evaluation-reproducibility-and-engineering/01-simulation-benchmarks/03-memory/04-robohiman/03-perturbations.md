# 扰动因子

RoboHiMan 借用 Colosseum 的 12 个扰动因子，把外观、几何、光照、场景、视角上的变化系统地叠加到任务上，用来考组合技能在环境变化下的鲁棒性。扰动只改环境呈现，不改任务目标和成功判定，因此同一个任务在不同扰动下是可比的：成功率随扰动下降多少，就是这个因子对技能组合的干扰有多大。

## 12 个因子

| 因子 | 作用对象 |
|---|---|
| `MO_Color` / `MO_Texture` / `MO_Size` | 操作物体的颜色、纹理、尺寸 |
| `RO_Color` / `RO_Texture` / `RO_Size` | 接收物体的颜色、纹理、尺寸 |
| `Light_Color` | 光照颜色 |
| `Table_Color` / `Table_Texture` | 桌面颜色、纹理 |
| `Distractor` | 场景中的干扰物 |
| `Background_Texture` | 背景纹理 |
| `Camera_Pose` | 相机位姿 |

MO（manipulation object）指被操作的物体，RO（receiver object）指接收物体，两者各有色、纹、尺三个因子，正好覆盖操作端与目标端的外观和几何。其余因子分别扰动光照、桌面、干扰物、背景和相机，从环境侧逼近真实部署里会遇到的变化。

## 扰动空间

采样范围来自 Colosseum，具体覆盖：

- 颜色：20 种。
- 纹理：213 种。
- 干扰物：78 个，取自 YCB 物体数据集。
- 物体尺寸：缩放范围随任务而定，例如橱柜 $[0.75, 1.15]$、抽屉 $[0.9, 1.15]$。
- 光照：RGB 值在 $[0.0, 0.0, 0.0]$ 到 $[0.5, 0.5, 0.5]$ 之间采样。
- 相机：对 front、left_shoulder、right_shoulder 三个视角施加扰动，位置偏移在 $[-0.1,-0.1,-0.1]$ 到 $[0.1,0.1,0.1]$，欧拉角在 $[-0.05,-0.05,-0.05]$ 到 $[0.05,0.05,0.05]$。

以 `Camera_Pose` 为例，一个 episode 会给三个视角各采一组落在上述范围内的位置偏移和欧拉角，整段执行都用这组固定视角，相当于把摄像头挪到一个略有偏差的位置再让模型从头做完任务。`MO_Size` 则按任务对应的缩放区间随机放缩操作物体，改变它在画面里的大小与抓取几何。

## None 与 All

评测时每个任务既跑不加扰动的基准实例（记作 None），也逐因子各跑若干实例，另加一档把所有 12 个因子同时打开（记作 All）。三档给出三个坐标：None 是无扰动上限，逐因子是单一变化下的敏感度，All 是所有变化叠加时的最坏情形。带扰动的实例化就是 AP、CP 两类任务变体的来源，10 个原子任务扩成 114 个原子实例、12 个组合任务扩成 144 个组合实例，都由这 12 个因子和 None/All 两档配出来。

沿这三档看下来，颜色（`MO_Color`、`RO_Color`）、纹理（`MO_Texture`、`RO_Texture`）以及 All 对组合技能最伤。值得注意的是修复途径：只用带扰动的原子数据训练，鲁棒性回升有限；只有在组合任务里也引入带扰动数据，模型才明显更稳。这说明扰动打击的主要不是单步技能本身，而是长链条里对物体的持续辨认——原子技能在扰动下尚能完成，但一旦要跨多个阶段反复重新辨认物体和场景，外观一变就更容易在某个衔接点认错，链条越长越明显。
