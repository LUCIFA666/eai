# HiMan-Bench 任务

HiMan-Bench 的任务分原子与组合两层。原子任务是两阶段的短交互，刻画机械臂与物体之间的一次基本操作；组合任务把多个原子技能链成多阶段长任务。两层任务名沿用 DeCoBench，任务定义搭在 RLBench / PyRep 之上，成功判定由仿真里的接近传感器或几何阈值给出。

## 原子任务

10 个原子任务覆盖抽屉、橱柜、簸箕三类场景。每个任务按机器人离散状态变化切成两个子阶段（先抓取或接近，再放置或推合），子阶段是组合任务的最小拼装单元。

| 任务 | 两个子阶段 | 成功判定 |
|---|---|---|
| `open_drawer` | 抓抽屉把手 → 拉开 | 目标抽屉拉开至少 0.15 m |
| `close_drawer` | 接近把手 → 推合 | 抽屉推到距全闭 0.03 m 内 |
| `put_in_opened_drawer` | 拿起桌面方块 → 放进抽屉 | 抽屉内接近传感器检测到方块 |
| `take_out_of_opened_drawer` | 拿起抽屉内方块 → 放到桌面 | 桌面接近传感器检测到方块 |
| `box_out_of_opened_drawer` | 拿起抽屉内草莓果冻盒 → 放到桌面 | 果冻盒被检测在抽屉外的桌面上 |
| `box_in_cupboard` | 拿起桌面物品 → 放进橱柜 | 橱柜内传感器检测到物品 |
| `box_out_of_cupboard` | 拿起橱柜内物品 → 放到桌面 | 桌面传感器检测到物品 |
| `broom_out_of_cupboard` | 拿起橱柜内扫帚 → 放到桌面 | 桌面传感器检测到扫帚 |
| `sweep_to_dustpan` | 拿起桌面扫帚 → 把灰扫进簸箕 | 全部灰尘颗粒进入簸箕 |
| `rubbish_in_dustpan` | 拿起桌面垃圾 → 丢进簸箕 | 垃圾被检测在簸箕内 |

其中 `box_in_cupboard`、`box_out_of_cupboard` 的操作物品在草莓果冻、午餐肉、糖三者间取一，`open_drawer` 等抽屉任务的目标抽屉在上、中、下三层间取一，这些取值差异连同扰动因子一起构成 AP 那 104 个变体。

## 组合任务

12 个组合任务把原子技能按语言指令链成多阶段长任务。每一步对应一个原子子阶段，模型要把这些子阶段排成正确顺序执行。子阶段数等于所含原子技能的子阶段之和，最长的两个（`put_two_in_different`、`take_two_out_of_different`）达到 9 步。

| 任务 | 子阶段数 | 链条简述 | 训练可见 |
|---|---|---|---|
| `put_in_without_close` | 4 | 开抽屉 → 放入 | 是 |
| `take_out_without_close` | 4 | 开抽屉 → 取出 | 是 |
| `put_in_and_close` | 5 | 开抽屉 → 放入 → 关抽屉 | 否 |
| `take_out_and_close` | 5 | 开抽屉 → 取出 → 关抽屉 | 否 |
| `put_two_in_same` | 6 | 开抽屉 → 两个方块依次放入同一抽屉 | 否 |
| `take_two_out_of_same` | 6 | 开抽屉 → 两个方块依次取出 | 否 |
| `put_two_in_different` | 9 | 两个方块分别放入两个抽屉，各含开关抽屉 | 否 |
| `take_two_out_of_different` | 9 | 两个方块分别从两个抽屉取出 | 否 |
| `box_exchange` | 4 | 橱柜取糖放桌面 → 桌面取午餐肉放橱柜 | 否 |
| `sweep_and_drop` | 4 | 垃圾丢簸箕 → 扫灰进簸箕 | 是 |
| `transfer_box` | 4 | 开抽屉 → 取果冻 → 放进橱柜（跨域） | 是 |
| `retrieve_and_sweep` | 2 | 橱柜取扫帚 → 扫灰进簸箕 | 否 |

12 个里只有 4 个进入训练数据（表中标注），其余 8 个在训练中从未出现，用来评未见组合的泛化。一部分任务要求跨域迁移：操作对象和场景在任务中途切换，例如 `transfer_box` 先在抽屉域取物、再切到橱柜域放物；`box_exchange` 则要在橱柜与桌面之间往返搬运两件不同物品。这类任务考的不是单步技能本身，而是调度与拼接：即便原子技能都已掌握，顺序错、衔接断、跨域时目标认错，长任务照样失败。

## 一个组合任务走一遍：transfer_box

以最能体现跨域的 `transfer_box` 为例。它的语言指令是把草莓果冻从抽屉取出再放进橱柜，拆成四个子阶段：抓抽屉把手、拉开抽屉、拿起抽屉里的草莓果冻、把草莓果冻放进橱柜。前两个子阶段属于抽屉域（对应 `open_drawer`），后两个跨到橱柜域（对应 `box_in_cupboard` 的放置阶段）。中途场景从抽屉切到橱柜，操作目标始终是同一个果冻盒，模型必须在切换点锁定同一目标，不因场景变化而认错物体。成功判定是终态复合判定：只有果冻盒最终被橱柜内的接近传感器检测到才算成功，中间开对了抽屉、抓对了果冻都不给部分分。

## 最长的链条：put_two_in_different

`transfer_box` 考的是跨域认物，`put_two_in_different` 考的是另一种失败面——长链条下的误差累积。它 9 个子阶段，是全体任务里最长的：开第一个抽屉、拿起第一个方块放进去、推合，再开第二个抽屉、拿起第二个方块放进去。链条越长，前面子阶段的位姿或抓取偏差越会顺着传到后面，一步没对准，后面几步大多跟着废掉；同时模型要在两个抽屉之间切换目标，还得记住第一个方块已经放好、别再去动它。`transfer_box` 即便原子技能都会，也可能在场景切换点认错物；`put_two_in_different` 则可能每一步都基本对，却因为九步累积的漂移在终态判定上差一点。两个例子合起来说明，组合任务的失败不是单一原因，跨域衔接和长链累积是两条不同的路径。

## 四类任务规模

原子与组合任务各自再按有无扰动分成两类，合成四类：

| 类别 | 含义 | 任务数 |
|---|---|---|
| A | 原子 | 10 |
| AP | 带扰动的原子 | 104 |
| C | 组合 | 12 |
| CP | 带扰动的组合 | 132 |

AP、CP 是 A、C 在 12 个扰动因子下实例化出的变体。四类任务是结果汇报的基本粒度：成功率分别在 A、AP、C、CP 上取平均。组合任务的成功一律按上面 `transfer_box` 那样的终态复合判定，整条长任务的最终目标状态达成才算成功。子阶段之间如何自动切换、切换边界怎么定，属于评测设置的一部分。
