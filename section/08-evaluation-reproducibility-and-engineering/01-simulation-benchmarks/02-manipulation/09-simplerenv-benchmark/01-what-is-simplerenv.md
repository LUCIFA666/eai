# SimplerEnv 是什么

把 SimplerEnv 放在仿真 Benchmark 这一章里讲，是因为它的定位和普通仿真环境不太一样。它不是让你从零训练一个策略的训练场，而是一块**测试板**——专门用来把已经存在的真实机器人策略放进仿真里跑评测。

## 本节目标

读完本节后，你应该能回答：

1. SimplerEnv 解决的是什么问题？为什么需要把真实机器人策略放到仿真里评测？
2. Visual Matching 和 Variant Aggregation 分别是什么意思，各自解决什么？
3. SimplerEnv 和普通训练用仿真环境（如 ManiSkill2、RLBench）在定位上有什么不同？
4. 本节 smoke test 的边界在哪——什么能证明、什么不能证明？

## 为什么需要 real-to-sim 评测

真实机器人评测有三个绕不开的痛点：

- **成本高**：每次评测都要占用真机时间，一台机器人一天能跑的 episode 数量有限。
- **复现难**：光照、物体摆放、背景杂物等环境因素每次都在变，两次评测之间很难做到"只改变策略，其他完全不变"。
- **速度慢**：真实物理世界不能加速，跑几百个 episode 可能需要好几天。

仿真的优势正好补上了这些短板：环境可以固定（同一个 seed 同一场景）、可以加速（不受物理时间约束）、可以并行（多开环境同时跑）。所以自然就有了这样一个想法：把真实机器人策略的 checkpoint 拿到仿真里去跑，用仿真结果来做模型选择、失败分析和回归测试。

SimplerEnv 就是这个想法的具体实现。它不是自己造一套新任务和新环境，而是**复刻真实机器人评测场景**，让策略在仿真里看到的画面、拿到的观测、执行的动作空间，尽量贴近真实评测。

## 两个核心思路

SimplerEnv 的设计围绕两个概念展开：

### Visual Matching（视觉匹配）

真实机器人的策略（尤其 VLA 模型）通常以图像作为输入。如果仿真渲染的画面和真实相机拍到的画面差别太大，策略的行为就可能偏离真实评测中的表现。

Visual Matching 的做法是：

- 把真实评测场景的背景图叠到仿真渲染的画面上。
- 调整机器人和物体的贴图，让颜色、纹理尽量贴近真实场景。
- 让仿真相机的内参和外参与真实相机的标定结果对齐。

这样做的目标不是"让仿真画面像照片一样逼真"，而是**让策略"看到"的东西和真机上看到的东西足够接近，从而产生一致的输出**。

### Variant Aggregation（变体聚合）

真实评测时，同一个任务可能在不同背景、不同光照、不同干扰物摆放的情况下表现不一样。如果只在一种场景下评测，结果可能不具有代表性。

Variant Aggregation 的做法是：

- 对同一个任务构造多个变体：换背景、换桌面纹理、加干扰物、调光照方向和色温。
- 在每个变体下都跑策略，记录结果。
- 最后把所有变体的结果汇总，得到一个更稳定的成功率估计。

这两个思路结合起来：Visual Matching 负责让**输入**对齐，Variant Aggregation 负责覆盖**输出**的统计方差。

## 和普通仿真环境的区别

这里有必要把 SimplerEnv 和它依赖的 ManiSkill2 区分清楚：

| | ManiSkill2 | SimplerEnv |
|---|---|---|
| **定位** | 通用机器人操作仿真平台 | 真实机器人策略的 real-to-sim 评测环境 |
| **目标** | 训练策略、算法研究 | 评测已有策略、模型选择、回归测试 |
| **任务来源** | 自己定义的任务集 | 复刻 Google Robot / WidowX 等真实评测场景 |
| **观测** | 多种模态（RGB-D、点云、状态等） | 以单视角 RGB 为主，对齐真实相机画面 |
| **视觉** | 标准 SAPIEN 渲染 | 加入真实背景叠加、贴图匹配 |
| **策略** | 从零训练 | 加载预训练 checkpoint 做推理 |

简单说：ManiSkill2 是"盖训练场的工具"，SimplerEnv 是"摆在训练场出口的测试台"。本节用的是测试台一侧。

## 本节 smoke test 的边界

这一节我们不会加载 RT-1、Octo 或任何 VLA 模型。几个原因：

1. 策略 checkpoint 动辄几个 GB，初学者下载和加载都可能遇到问题。先跑通环境，再接入策略，排错效率更高。
2. 环境本身可能因为 NumPy 版本、渲染后端、CUDA 配置等原因挂掉。如果一上来就同时调试环境和模型，问题来源会很难定位。
3. smoke test 的目的是验证 `install → import → make → reset → step → render → save` 完整链路，确认**环境本身没问题**。至于策略能不能完成任务，那是下一阶段的事。

本节所有实验中的动作（零动作、小随机动作）都不是策略输出，因此 `success=false` 是预期结果，不代表环境失败。

## 小结

- SimplerEnv 是面向真实机器人策略的 real-to-sim 评测环境，不是训练框架。
- Visual Matching 负责对齐策略输入（让仿真画面贴近真实相机），Variant Aggregation 负责覆盖统计方差（多场景平均）。
- 它依赖 ManiSkill2 提供底层任务环境，但定位不同：一个是训练场工具，一个是测试台。
- 本节只做最小闭环的 smoke test，不加载策略 checkpoint，目的是先把环境链路跑通。
