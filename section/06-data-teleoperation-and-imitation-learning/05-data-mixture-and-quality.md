# 数据配比与质量评估

本节介绍机器人学习数据的"多少才够、什么才算好"：训练数据混合（mixture）的配比设计、数据质量过滤与去重、以及数据规模化（data scaling）的经验规律。前四节解决"怎么存、怎么转、从哪来、怎么采"，本节解决"采回来的数据如何配比和验收才能训出好策略"。

## 需要覆盖

- 数据混合配比：机器人数据与 web 多模态数据的 co-training 配比、跨具身数据混合权重（可参照 OpenVLA / Open X-Embodiment 的 mixture 设计与 StarVLA 的 mixture registry 页面）。
- 质量过滤：失败轨迹要不要留、抖动与停顿段的处理、时间对齐与丢帧检测、语言标注质量。
- 去重与多样性：任务/场景/物体分布的覆盖度量，避免"一千条同一任务"的伪大数据。
- Data scaling 经验：任务内样本数与成功率的关系、多任务与泛化的边际收益、何时该采新数据而不是继续训练。
- 验收产物：一份数据配比说明（mixture 表）与一份质量检查报告（过滤规则、通过率、抽样复核）。
- 与第 7 章的衔接：配比如何进入具体训练框架的 dataset/mixture 配置。
