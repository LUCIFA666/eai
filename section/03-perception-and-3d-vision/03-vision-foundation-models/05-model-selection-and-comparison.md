# 不同模型的差异与选型

> 难度：[中级] | 预计用时：60 分钟
> 先修：[Point Foundation Model](04-point-foundation-models.md)
> 阅读提示：本页不再展开单个模型原理，而是专门做横向比较与任务选型。

目标：把 CLIP / SigLIP、DINO / DINOv2、单目深度模型、point foundation model 的职责边界并排放在一起，帮助读者面对具体任务时知道先用哪类模型、再补哪类模块。

## 先建立总判断

视觉基础模型的真正价值，不是“谁最大、谁最强”，而是：

**面对具体任务时，知道先调用哪一类中间能力。**

如果这个判断做错了，后面常见的连锁问题包括：

- 用 CLIP 去硬做局部跟踪
- 用 DINO 去硬接文本查询
- 把单目深度直接当抓取真值
- 把 point feature 误当成位姿或控制量

所以本页的任务是统一做一轮职责对比。

## 一张总表先把差异排开

| 模型族 | 典型输入 | 典型输出 | 最擅长的问题 | 最常见的误用 |
|---|---|---|---|---|
| CLIP / SigLIP | 图像、文本 | image/text embedding、相似度 | “这是不是我要找的对象” | 把语义分数当抓取置信度 |
| DINO / DINOv2 | 图像 | patch feature、dense feature | “哪里和哪里在局部结构上相似” | 把局部 feature 当文本语义分数 |
| 单目深度模型 | 单张 RGB | 深度图 | “这一像素离相机多远” | 把深度图直接当执行真值 |
| Point Foundation Model | 点云 | 3D feature、点级或对象级表征 | “哪些 3D 局部结构重要或相似” | 把 point feature 当物理坐标 |

## 再用一句话概括每类模型

- CLIP / SigLIP：把自然语言接入视觉系统。
- DINO / DINOv2：把局部视觉结构匹配做稳。
- 单目深度模型：给二维图像补距离。
- Point Foundation Model：给点云补 3D 表征。

如果只需要一个“速记版”：

```text
找谁 -> CLIP
哪里像哪里 -> DINO
离多远 -> depth
3D 结构像什么 -> point model
```

## 面对任务时怎么选

### 场景 1：找桌上的红色杯子

优先考虑：

- `CLIP / SigLIP`

原因：

- 任务首先是文本到视觉候选的语义匹配

后续通常还要补：

- `GroundingDINO / SAM`
- 深度或点云
- pose

### 场景 2：连续两帧里跟住同一把抽屉把手

优先考虑：

- `DINO / DINOv2`

原因：

- 任务首先是局部结构对应，不是语言检索

后续通常还要补：

- 跟踪状态管理
- 分割稳定化
- 几何校验

### 场景 3：只有单张 RGB，但需要估计对象大概距离

优先考虑：

- 单目深度模型

原因：

- 任务首先缺的是距离信息

后续通常还要补：

- 尺度校验
- 反投影
- 坐标系变换

### 场景 4：点云已经有了，需要理解 3D 局部结构

优先考虑：

- `Point Foundation Model`

原因：

- 任务首先需要的是 3D feature，而不是 2D 语义匹配

后续通常还要补：

- 对象级汇总
- 位姿恢复
- 接触约束

## 一张流程图看模型怎么组合

机器人系统常见的不是“单模型通吃”，而是模型串联：

```text
语言目标
  -> CLIP / SigLIP
  -> GroundingDINO / SAM
  -> depth
  -> point feature
  -> pose / affordance / control
```

另一类链路则更偏向跟踪与对应：

```text
当前图像 + 历史图像
  -> DINO / DINOv2
  -> 局部对应 / 跟踪
  -> 稳定 mask 或 pose
  -> 进入后续几何与执行层
```

这两条链路的起点就不同，因此第一步模型选择也不同。

## 什么时候绝不能只停在 foundation model 输出

无论前面哪类模型表现得再强，下列问题仍然不能省：

- 结果在哪个 `frame_id` 下
- 深度或点云是否有效
- 位姿是否稳定
- 结果是否过时
- 当前是否可执行还是应当重观察

因此可以把本节所有模型统一归纳为一句话：

**它们强化的是感知前半段的语义、匹配和表征能力，而不是替代整条几何与控制链。**

## 选型时最容易犯的四个错误

| 错误 | 更合适的改法 |
|---|---|
| 用 CLIP 直接决定抓不抓 | 让 CLIP 只负责语义候选，抓取还要看几何与位姿 |
| 用 DINO 直接回答文本目标 | 先用 CLIP 做语义筛选，再用 DINO 做局部对应 |
| 单目深度一出图就进入控制 | 先做尺度检查和坐标系转换 |
| point feature 一高就当接触点 | 先把 feature 和几何量、接触约束分开 |

## 一个简化的选型决策树

```text
任务先问的是“谁”？
  -> CLIP / SigLIP

任务先问的是“哪里和哪里像”？
  -> DINO / DINOv2

任务先缺的是“离多远”？
  -> 单目深度模型

任务先缺的是“点云里的 3D 结构理解”？
  -> Point Foundation Model
```

如果一项任务同时涉及多种问题，就按链路组合，而不是试图用单个模型硬覆盖全部步骤。
